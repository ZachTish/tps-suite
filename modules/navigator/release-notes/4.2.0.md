# TPS Notebook Navigator 4.2.0

## Intent

Make notes and line entities browsable as first-class vault records, without turning them into files or duplicating TPS
Global Context Menu's entity parser.

## Changes

- Adds an expandable **Types** section to the navigation pane with Notes, Checkboxes, Bullets, Headings, and a nested
  **Kinds** collection populated from GCM's generic Entity Index v3.
- Shows the selected collection in a standalone virtualized list rather than attaching it to file rows, so large
  vault-wide collections are not constrained by the attached-provider row ceiling.
- Opens note entities directly. Checkbox, bullet, heading, and Kind-backed line entities re-resolve their locator at
  activation time and open their current source line through Obsidian's workspace and editor APIs.
- Applies the active Navigator profile, hidden-folder/file/property/tag filters, file-visibility rules, and **Show
  hidden items** override to both counts and rows.
- Adds native persisted selection, back/forward history, keyboard navigation, expansion, scrolling, responsive layout,
  and plain-text label/path search for Types.
- Hides file-only selection, pin, drag, rename, sort, group, appearance, and note-creation actions while a Type is
  selected.
- Adds a default-on **Show Types in navigation** control to the flat **TPS integration** settings destination. The
  setting stays TPS-owned during a one-way upstream settings import.
- Advances the public API to 2.4.0 with an additive `type` navigation-item variant and preserves the exact existing
  folder, tag, property, and none shapes.

## Compatibility and migration

- Minimum supported Obsidian version remains 1.11.0.
- TPS Global Context Menu 1.14.0 is the tested Entity Index v3 baseline for populated Types collections.
- If GCM is missing, disabled, incompatible, or its index cannot complete, Types fails closed with a visible status row
  and does not parse or mutate notes itself.
- No note-data migration is required. Existing installs receive the new setting at its enabled default, and disabling it
  safely falls back from a previously selected Type to the vault root.
- Upstream Notebook Navigator remains co-installable; all added storage, navigation, DOM, events, and API state remain
  TPS-namespaced.

## Validation

- Passed the complete Vitest suite: 195 files and 2,067 tests.
- Passed formatting, ESLint, TypeScript, stylesheet lint, TPS source-namespace, compiled-artifact, and whitespace gates.
- Built the final 4.2.0 production bundle and atomically deployed it to the `tps-notebook-navigator` runtime in the
  Obsidian Plugin Test Vault without replacing runtime-owned settings.
- Reloaded the plugin in Obsidian 1.12.7 and verified Notes, Checkboxes, Bullets, Headings, note-backed Kinds, and
  line-backed Kinds against TPS Global Context Menu 1.14.0. Note rows opened their note; structural and Kind line rows
  opened their exact current line while preserving the selected Type collection.
- Verified filtered counts and rows, fenced-code exclusion, search, keyboard movement, history guards, navigation
  reordering, the flat settings toggle, file-only action suppression, and the shared responsive/mobile interaction path.

## Known limitations

- Types search is intentionally plain text over entity labels and source paths. File-only advanced operators and
  Omnisearch ranking do not apply.
- Line activation opens the source editor so the exact current line can be focused.
- GCM index failures are reported as a collection status; the Navigator does not return a knowingly partial result.
- Physical-device touch behavior remains subject to the host WebView; desktop test-vault checks and automated responsive
  behavior cover the shared activation path.
