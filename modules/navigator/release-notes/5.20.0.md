# TPS Notebook Navigator 5.20.0

This backward-compatible minor release makes the Navigator compatible with root-level, metadata-identified TPS
templates. Calendar and folder-note template choices use GCM's shared template rule when present and retain the prior
folder fallback otherwise.

Unresolved Templater or double-brace expressions in a note's frontmatter title now display as the file's basename
throughout Navigator's normal name path.

Minimum Obsidian: 1.11.0.
