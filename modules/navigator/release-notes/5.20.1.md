# TPS Notebook Navigator 5.20.1

This backward-compatible patch makes Core Daily Note ownership deterministic across TPS plugins. Navigator delegates
Daily Note identity and creation to GCM when available and otherwise uses one coherent Core folder, format, and template
snapshot.

- Flat-vault calendar, food, workout, and task records are no longer accepted merely because their filenames contain a
  date. GCM Daily Notes v4 also binds a confirmed creation to the exact path that Navigator displayed; constrained
  confirmations fail closed on older providers.
- Starting or incompatible GCM providers, startup-shaped Core settings, concurrent same-date actions, external creation
  races, and localized date digits fail closed instead of producing a duplicate.
- Newly owned templates run through Templater exactly once. Mature existing notes remain byte-stable, and failed output
  is retained with a hidden EOF marker rather than deleted.
- Independent Notebook Navigator calendar-note mode is unchanged.

Minimum Obsidian: 1.11.0.
