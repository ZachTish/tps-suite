# TPS Notebook Navigator 8.3.0

Sort **File types** and **Properties** labels directly from their navigation-header context menus: **Change sort order** offers A to Z, Z to A, and frequency in either direction. File types also retains Default order. **Reorder navigation** opens the existing manual drag editor; File types includes up/down controls.

This additive **minor** release retains minimum Obsidian **1.11.0**. Tested in **Obsidian Plugin Test Vault** on macOS/Obsidian **1.14.4**, ready for the user's BRAT pull. No production installation is claimed.

## Configuration and scope

- Reuses existing `typeNavigationSortOrder`, `rootTypeOrder`, `propertySortOrder`, and `rootPropertyOrder`. No new settings, defaults, schema or migration.
- Choosing an automatic Properties sort clears a saved manual root order, so the choice takes effect. Existing local/synced preference persistence remains authoritative. File types retains its saved manual order for later reuse.
- Properties uses its existing global navigation sort, which also controls default value ordering. Explicit per-property child-sort overrides still take precedence.
- File-list ordering, note membership and frontmatter are unchanged. No scans, note writers, timers, caches or background work are added.
- One native submenu; existing root-menu dismissal before actions is reused for mobile. Settings destination map, default route and persisted-state contract remain unchanged.

## Validation

- **35/35 new regressions** cover every mode/checkmark, no-op choices, current settings after replacement, local/synced save ownership, manual handoff, native-menu dismissal, and actual section-menu wiring. A **50-menu burst makes zero vault reads, writes or inventories**. Host menu rendering and preference services are stubbed in those source tests.
- **21/21 adjacent ordering/preference tests** and the final versioned full suite: **3,403/3,403 in 288 files**, Node **24.19.0**.
- Full ESLint: zero errors, the existing 26 warnings. Style lint, namespace, artifact/operational identity, scoped source/test formatting, TypeScript and string/locale checks pass. Separate ordinary final build deploys only to TEST.
- Targeted TEST plugin reload verifies **8.3.0**, GCM **8.2.0**, and all eight active TPS consumers enabled.
- Installed foreground UI uses actual Properties and File types context menus. Reverse alphabetical choices change visible labels; Properties frequency changes its saved preference; manual handoff opens the existing reorder editor. Saved preferences are verified on disk and restored afterward.
- Original expansion/search presentation is restored. Other recorded TPS plugin data remains byte-identical. Navigator data differs only by its existing version acknowledgement; normalizing that field to the prior version reproduces the original SHA-256. No notes, outbound automation or production files are touched.

## Limits

Physical iPhone presentation, minimum-version acceptance and production installation remain pending. Installed UI QA uses a desktop native menu; mobile root dismissal is covered in source tests. The operation counts apply to the menu owner, not the entire settings-refresh/render pipeline. No startup or navigation-speed claim is made.
