# TPS Notebook Navigator 4.0.0

## Intent

Provide an experimental TPS-owned Notebook Navigator fork that can run beside upstream Notebook Navigator, accept
modular row providers, and remain practical to merge with later upstream releases.

## Changes

- Introduces the separate `tps-notebook-navigator` plugin, view, command, event, drag-payload, DOM/CSS, Style Settings,
  local-storage, IndexedDB, and settings-transfer identity boundary.
- Adds a versioned generic Rows API and provider registry. Provider records remain transient UI rows rather than fake
  vault files, and provider failures cannot replace the ordinary file list.
- Adds optional TPS Global Context Menu task rows beneath their exact visible notes, with title activation,
  keyboard/context-menu ownership, optimistic checkbox mutation, visible rollback, completed-task control, and a
  per-note limit.
- Keeps large lists bounded through 64-note progressive query passes, per-note cache limits, fair row allocation,
  lifecycle-aware invalidation, and a 1,000-row global ceiling.
- Adds an explicit one-way import for recognized upstream settings while preserving TPS-only settings and never writing
  to the upstream plugin.
- Adds an idempotent namespace maintenance tool, standalone-safe build resolution, artifact identity checks, and an
  upstream synchronization guide.

## Compatibility and migration

- This is an intentionally separate major-version product line, not an in-place upgrade of upstream Notebook Navigator.
- Upstream Notebook Navigator and TPS Notebook Navigator can remain enabled and open side by side.
- No note-data migration is required. TPS settings and caches use separate storage identities.
- TPS Global Context Menu 1.13.1 or later is the tested interactive task-row baseline. Missing or incompatible GCM
  installations leave the ordinary file navigator working and contribute no task rows.
- Minimum supported Obsidian version is 1.11.0.

## Validation

- Under the required Node 24 runtime, all 179 Vitest files and 1,982 tests passed. TypeScript, ESLint, Stylelint,
  Prettier, the TPS namespace check, and the final artifact-identity check also passed.
- The final production-mode bundle was deployed only to **Obsidian Plugin Test Vault**, with source/runtime artifact
  parity verified.
- In reloaded Obsidian 1.12.7, upstream Notebook Navigator and TPS Notebook Navigator were enabled and opened as
  separate leaves. Optional GCM rows rendered the two open tasks beneath `Inbox/Synthetic Task Sink.md`; title
  activation opened the exact source line, and checkbox mutation completed then reopened that exact task through GCM
  1.13.1.
- The synthetic fixture was restored byte-for-byte, the optional task-row setting was restored to disabled, and that
  setting persisted across reload with no provider rows rendered. Production was not accessed.

## Known limitations

- TPS task rows are optional and currently use GCM's task API; they do not become draggable, renamable, or
  multi-selectable file records.
- Provider queries are limited to files already represented in the current list and do not scan unrelated folders.
- Upstream settings import is a snapshot, not synchronization. Run it again explicitly to copy later upstream changes.
- Future upstream releases still require a reviewed Git merge plus the documented namespace and side-by-side validation
  gates.
