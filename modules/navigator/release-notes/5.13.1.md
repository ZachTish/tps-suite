# TPS Notebook Navigator 5.13.1

This patch makes exact-line tag filters authoritative for Checkboxes, Bullets, and Headings.

## Fixed

- A query such as `type:structural:task #hca` now accepts only tasks whose own GCM tag list contains `hca` or a nested
  `hca/...` tag.
- A tag on the owning note can no longer make an untagged task pass the filter, even when line-property inheritance is
  enabled.
- A locally tagged task can match inside an untagged note.
- Negative tags, tagged/untagged operands, and tag/property `AND`/`OR` expressions use the same exact row-local
  projection.
- Folder, date, extension, task-state, and active navigation constraints continue to scope source files before row
  filtering.

No settings or data migration is required. Minimum supported Obsidian version remains 1.11.0.

## Validation

- Focused exact-line source-scope and row-filtering regressions.
- Full Vitest, ESLint, Stylelint, TypeScript production build, TPS namespace/artifact gates, operational-identity gate,
  and atomic test-vault runtime deployment.
- Visual automation is intentionally skipped while the active Obsidian window is the production vault rather than the
  isolated test vault.
