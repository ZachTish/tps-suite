# TPS Notebook Navigator 6.4.1

Reuse locale comparison during file-type catalog sorting. Labels, accent/case-insensitive comparison, path tie-breaking, classification and event batching are preserved.

Backward-compatible patch: no settings, defaults, data migrations or public API contract changes. Minimum Obsidian **1.11.0**.

## Validation

3,079 tests across 270 files (also verified on Node 24.19.0); ESLint zero errors and 24 existing warnings; namespace/artifact/operational identity checks. TypeScript and a separate final production build passed; deployment reported `target=test`. Final artifacts were explicitly reloaded in **Obsidian Plugin Test Vault**.

The four-open navigation trace dropped from eight global editor reconfigurations to zero and from five focus requests to four. A separate synthetic create-plus-six-opens CPU profile measured Navigator catalog refresh at approximately **832 ms before / 26 ms after**; the updated Health service performed **zero full index rebuilds** during that settled run. These are local diagnostic samples in a development vault of roughly 32,000 files, not a controlled benchmark or an overall device-speed guarantee.

Installed QA preserved note bodies through Reading/Source/Live Preview transitions, and retained cursor and scroll position after native cursor scrolling settled. A synthetic food entry updated from 210 to 320 kcal without reloading the Health index. Five QA notes were archived, temporary probes removed, navigation restored, and no preferences were saved or outbound automation enabled.

Physical iOS and production-vault acceptance remain user testing.
