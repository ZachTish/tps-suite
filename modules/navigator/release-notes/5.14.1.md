# TPS Notebook Navigator 5.14.1

This patch fixes the recurring blank strip beneath the desktop list scroll viewport.

## Fixed

- The desktop horizontal list pane now uses explicit rows for its title/search chrome, scroll panel, optional calendar,
  and toolbar.
- The scroll panel always receives the complete remaining pane height after workspace, tab, header, or search-bar size
  changes instead of retaining an older intrinsic flex height.
- Mobile, vertical, and single-pane sizing rules remain unchanged.

## Compatibility and migration

- This is a backward-compatible layout fix with no settings, note, cache, or data migration.
- Public API 3.3.0 is unchanged.
- Minimum supported Obsidian version: 1.11.0.

## Validation

- Focused generated-namespace-aware layout and release coverage passed 12 tests across 3 files.
- The full suite passed 231 test files and 2,587 tests. TypeScript, ESLint, Stylelint, TPS source namespace, operational
  identity, artifact identity, and production build gates passed; ESLint reported 19 existing warnings and no errors.
- Every changed file passes Prettier. The repository-wide check still reports three previously committed unrelated
  files; they were preserved rather than folded into this patch.
- The final build deployed to the isolated Obsidian Plugin Test Vault. All three runtime artifacts match the tested
  source artifacts byte-for-byte, and runtime-owned `data.json` was preserved. Production was not modified.

## Known limitations

- The patch is scoped to the desktop horizontal two-pane layout shown in the report. Mobile, vertical, and single-pane
  layouts continue to use their existing dedicated contracts.
- UI automation is skipped while the active Obsidian window is the production vault; the isolated test-runtime artifacts
  are verified byte-for-byte instead.
