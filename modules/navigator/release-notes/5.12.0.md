# TPS Notebook Navigator 5.12.0

This release makes the vault root the complete mixed-resource scope and makes compact appearance apply consistently to
attached task/provider rows.

## Changes

- Selecting the vault root now traverses all visible subfolders instead of returning only files directly beneath `/`.
- The root continues to respect the active profile's supported-file visibility, hidden-content rules, and
  excluded-descendant folders.
- The descendants control is visibly active and fixed at the root; ordinary folder, tag, and property scopes retain the
  existing user-controlled preference.
- Compact appearance now condenses attached task/provider rows using the same native file-row renderer and virtual
  measurements as the rest of the list.

## Validation

- Focused root-scope and compact provider-row regression tests.
- Full Vitest suite: 2,568 tests passed across 229 files.
- ESLint completed with no errors; existing deprecation/exhaustive-deps warnings remain unchanged.
- Stylelint, TypeScript production build, TPS namespace/artifact gates, operational-identity gate, and atomic test-vault
  runtime deployment passed.
- Minimum supported Obsidian version: 1.11.0.
- Visual automation was intentionally skipped because the active Obsidian window was the production vault, not the
  isolated test vault.

Tested through the Obsidian Plugin Test Vault build/deployment pipeline and ready for the user's BRAT pull. The release
does not directly install or reload the production vault.
