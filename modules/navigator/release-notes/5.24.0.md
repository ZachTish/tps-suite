# TPS Notebook Navigator 5.24.0

This minor release integrates the annotated upstream Notebook Navigator 3.3.6 tag (`748f02c9`), covering upstream
releases 3.3.4 through 3.3.6, while preserving the fork's co-installable TPS identity and integrations.

- Folder, tag, property, and supported Type scopes can independently override Date and Parent folder visibility.
- Structured hover tooltips can show path, dates, word count, and the same filtered/ordered tag pills used by file rows.
- None is an explicit ungrouped mode. Custom remains reserved for manual frontmatter group headers, and the TPS all-Tags
  and top-level property-key scopes retain their automatic default grouping, including untagged and blank-property
  notes.
- Public API 3.6.0 accepts and reports `groupBy: 'none'`; every earlier API 3.x grouping and provider contract remains
  valid.
- Markdown word/character processing follows active consumers and custom group-header metadata instead of running for
  tooltip-only or inactive settings. Aggregate Tags and present blank property keys remain valid TPS consumers.
- Multi-file drag payloads retain every selected path on macOS. Narrow single-pane startup keeps the configured starting
  pane, while later dual-to-single transitions continue to enter the file list.
- Mobile context submenus close reliably after an action, folder-note selection remains stable, and New canvas is hidden
  while Obsidian's Canvas core plugin is disabled.
- Folder-note naming now uses one `{{folder}}` pattern with migration from prior fixed names. TPS/GCM template identity
  remains available in the picker, and one-way upstream settings import explicitly preserves all TPS-only architecture,
  Type, integration, and migration values.
- The About area includes a toggle for automatic startup release notes. Manual What's New access remains available.
- The newly introduced Better Paste card icon uses a TPS-owned global icon ID, so it cannot collide with the
  co-installed upstream plugin.
- Minimum supported Obsidian remains 1.11.0. No note schema or IndexedDB migration is required.
- Known limitation: external provider Types retain provider-owned presentation, and source-backed rows cannot use
  file-owned custom headers; choose None for their explicit ungrouped presentation.

Validation passed 259/259 test files and 2,994/2,994 tests, TypeScript, ESLint, Prettier, stylelint, all TPS
namespace/artifact/operational-identity gates, and the mandatory separate production-mode build. The final 5.24.0
artifacts were deployed atomically to the isolated test vault and reloaded with upstream Notebook Navigator still
enabled; production was not accessed. This release is ready for a BRAT pull after publication.
