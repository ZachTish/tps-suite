# TPS Notebook Navigator 5.20.2

Native Markdown records now remain stable on disk while displaying their readable canonical titles in Navigator.

- When no explicit Navigator frontmatter display-name field provides a usable value, a record verified through GCM's
  native-records API v2 or newer displays its canonical title instead of an opaque identity filename such as
  `item_<uuid>`.
- A strict whole wikilink title displays its alias, or its readable target basename when no alias exists.
  Backslash-escaped wikilink punctuation remains literal; malformed links, embedded syntax, and unresolved templates
  fail back safely to the filename.
- GCM API load, replacement, and unload refresh visible names, search evidence, metadata access, and title sorting
  together, including selected file-backed Types.

The change is presentation-only: it does not rename files, edit frontmatter, change settings, or persist a title cache.
An explicitly configured Navigator frontmatter display-name field remains authoritative. Legacy mode, ordinary files,
unavailable or incompatible GCM, and unverified records retain their previous filename behavior.

Minimum supported Obsidian remains 1.11.0.
