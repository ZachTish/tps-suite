# TPS Notebook Navigator 6.5.1

The title row setting now acts as a maximum. A short note title uses one row; a longer title wraps only as far as the configured two- or three-row limit. This removes the blank second line previously reserved for every note.

- Standard and compact note lists resize when titles change or the available width changes.
- Existing preview, date, tag, property and thumbnail spacing is preserved.
- The virtualizer measures the rendered title using its existing observer. No extra settings, observer, migration, note writer or background automation was added.
- Settings and content changes retain measured title sizes even while scrolling.

## Compatibility and limits

Backward-compatible patch; minimum Obsidian 1.11.0. No configuration changes are needed. The maximum remains the estimate for unmounted rows until measured. Provider-generated non-file rows retain their existing sizing. Mobile line metrics have automated coverage; physical iPhone acceptance remains outstanding.

## Validation

All 3,107 tests across 271 files passed, including ten added sizing regressions covering standard/compact titles, previews/dates/properties, thumbnail floors, mobile/fractional line heights and unmeasured rows.

ESLint passed with zero errors and 24 pre-existing advisory warnings. Style lint, namespace, operational/artifact identity, strings/locales and TypeScript checks passed. The separate final production build completed successfully, followed by a targeted plugin unload/load. No new runtime errors were recorded during this QA; the developer error buffer retains an older unrelated CLI evaluation error.

Installed Obsidian Plugin Test Vault QA verified short and wrapped titles at 36/56 px in standard mode and 28/48 px in compact mode; one-, two- and three-row limits; short-to-long-to-short renames; and narrow-to-wide-to-narrow pane changes. The final build is deployed and reloaded only in the test vault. Synthetic fixtures are archived and original test settings restored. Production installation is separate.

Tested in the test vault and ready for the user's BRAT pull.
