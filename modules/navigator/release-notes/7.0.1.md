# TPS Notebook Navigator 7.0.1

Fixes note titles overlapping their leading icons or preview text. A generic virtual-list CSS rule also matched the title elements measured since 6.5.1. Removing that redundant rule keeps titles in normal text flow; existing explicit row classes continue positioning virtual rows.

Short titles still use one line when two or three rows are allowed. Longer titles continue to wrap and truncate at the configured limit. Compact lists and inline rename titles use the same corrected layout. No settings, APIs, note data, or tag classification changes are included.

This backward-compatible fix is a patch release. Minimum Obsidian: **1.11.0**. Tested in **Obsidian Plugin Test Vault** on Obsidian 1.14.2 and ready for the user's BRAT pull. Production has not been updated by this release task. Physical iPhone verification remains outstanding.

## Validation

- 63 focused layout/measurement checks and the full suite: **3,144 tests in 271 files passed**.
- ESLint: zero errors, 24 existing advisory warnings. Style lint, TypeScript, string/locale, namespace, operational identity and artifact identity checks passed.
- Separate final production-mode build deployed the final artifacts to the test vault; Navigator was reloaded after refreshing cached manifests.
- Before: installed titles computed as `position: absolute`, overlapping icons and other content. After: `position: static` with an independently positioned virtual wrapper.
- Rendered standard and compact layout probes: 6 px icon/title gap; 20 px short titles and 40 px wrapped titles. Temporary DOM probes were removed; no notes or settings were edited. Runtime settings remained byte-identical. A current app screenshot confirmed the corrected title/preview layout.
