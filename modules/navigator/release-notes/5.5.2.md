# TPS Notebook Navigator 5.5.2

## Fixed

- Built-in source-backed Types such as Checkboxes no longer show a nonzero navigation count followed by an empty **No
  items found** list.
- Ordinary Type selection now trusts the already visibility-filtered Type snapshot used by the navigation count instead
  of applying a second independently memoized source allowlist.
- Active Filter Search continues to narrow Type rows through its owning-note source scope, so search facets remain
  unchanged.

## Compatibility and validation

- Backward-compatible patch with no settings or note-data migration.
- Minimum supported Obsidian version: 1.11.0.
- Focused Type routing/provider regressions, all 229 test files, lint, formatting, namespace/identity gates, TypeScript,
  production build, artifact checks, and test-vault deployment passed.
- The running Obsidian window was the production vault, so UI automation was intentionally not performed there.
  Production was not modified.
