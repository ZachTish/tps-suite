# TPS Notebook Navigator 5.23.0

This release preserves the useful visual organization from TPS rules without turning generated presentation into
intimidating note properties.

- Generated GCM icon, color, and sort values are consumed through the transient version-1 presentation overlay and never
  inserted into frontmatter, MetadataCache, property trees, search evidence, or pills.
- Authored frontmatter wins, then an explicit Navigator appearance, then generated presentation as the final display
  fallback.
- Generated values participate only in the file rows and configured property sort/group surfaces that need them; they do
  not impersonate authored manual-sort state.
- Batched revision subscriptions and lifecycle guards refresh mounted views without a vault rewrite or indexing loop and
  reject stale provider responses.

Validation: 256/256 test files and 2,935/2,935 tests, focused presentation isolation/lifecycle/sort/group coverage,
TypeScript, string/style checks, a separate production build, byte-identical isolated test-vault deployment, reload, and
integrated UI verification. Minimum supported Obsidian: 1.11.0. Known limitation: without a compatible GCM presentation
provider, Navigator safely displays only authored and explicit local appearance data.
