# TPS Notebook Navigator 8.4.0

The file list can now group slash-delimited property values as a collapsible hierarchy. For example,
`transaction/financial/investment` appears under **transaction → financial → investment**. This additive **minor**
release retains minimum Obsidian **1.11.0** and is tested in **Obsidian Plugin Test Vault**, ready for the user's BRAT
pull. No production installation is claimed.

## Enable nested grouping

- In **Change sort and group**, group by the desired property, then select **Nested values** under **Property values**.
  **Flat values** remains available.
- For the global default, open **Settings → TPS Notebook Navigator → List pane → Default grouping** and choose
  **Property ‘key’ · Nested**. Add the key to **Grouping properties** first if it is missing.
- Existing flat/day/default behavior remains unchanged. Selecting a top-level Properties key keeps its implicit flat
  grouping until an explicit scope override is chosen.

## Behavior and ownership

- Parent counts include unique descendant notes and provider-row identities. A note with several values can appear in
  multiple exact-value groups; a shared ancestor counts it once.
- Parent collapse hides its subtree, child collapse survives parent reopening, and existing reveal/bulk-expand actions
  retain their owners. Range selection uses the final visible file indices. Pinning, no-value placement and existing
  group file sorting remain in use.
- Ordinary slash paths use the same splitter as navigation Properties. Links, URLs, malformed paths and combined-value
  tuples stay atomic; case-sensitive list identities remain distinct.
- Headers show local segments with full paths in tooltips, accessible collapse names and sticky headers. Indentation
  stops increasing after four levels, while logical depth remains intact. File rows retain their existing width and
  measurement.
- Ascending, descending and follow-sort modes use the existing `groupBy` field, with `property-path`,
  `property-path-desc` and `property-path-follow` prefixes. The public list snapshot reports configured/effective
  grouping. Source-preserving `line-property-path` encodings remain accepted as a contract; no line UI is added or
  re-enabled.
- No new persisted settings field, migration, note writer, watcher, cache, poller, repair or vault scan. The hierarchy
  follows existing native/provider composition and uses already collected metadata. Descendant memberships for
  unfiltered totals are collected only in nested mode by the existing count pass. Mixed provider groups omit
  denominators when no trustworthy total exists.

## Validation

- **40 new regressions** cover hierarchy counts, duplicate memberships, exact parent values, protected atomic values,
  case identities, collapse/reveal/bulk actions, search totals with hidden siblings/parents, order direction,
  provider/standalone composition, final selection indices, settings/menu controls, persisted/API encodings,
  labels/accessibility and capped indentation.
- Final versioned full suite: **3,454/3,454 tests in 292 files**, Node **24.19.0**. Full ESLint: zero errors and the
  existing 26 warnings. Style lint, namespace, artifact/operational identity, scoped source/test formatting, TypeScript
  and string/locale gates pass.
- A synthetic 4,049-note composition performs one existing metadata lookup per note in both flat and nested mode. The
  added hierarchy plus 100 root-collapse passes performs **zero additional metadata/body reads, writes or inventories**.
  These counts cover the pure composition owner, with synthetic metadata and host boundaries; they do not describe the
  entire React pipeline. Five hundred flat provider merges retain header identity and perform zero member-getter calls.
- The ordinary separate final build deploys only to TEST. A targeted reload verifies **8.4.0** with all eight active TPS
  consumers enabled; outbound automation remains disabled.
- Installed foreground macOS/Obsidian **1.14.4** QA uses the actual sort/group menu and List pane default selector. Six
  synthetic notes verify **transaction 5**, **financial 3**, **investment 1**, and **food 2**, including a multi-valued
  note. Parent/child collapse retains child state, descending order reverses sibling groups, and a search for the
  investment note shows **1/5**, **1/3** and **1/1**.
- Twenty installed parent collapse/expand actions perform **zero raw/cached reads, note-write attempts or vault
  inventories**, matching the flat baseline's zero counts. Four warm flat/nested presentation switches make zero
  raw/cached reads and write attempts, with eight existing inventory calls total (two per switch). Timed samples
  including two animation frames are **247, 216, 215 and 215 ms**. This is a combined foreground TEST flow, not a
  cold-start, production, physical-input or speed-improvement claim; animation-frame delay warnings occurred in this
  large development vault.
- Test preferences, presentation and original note are restored through existing owners. A cleanup check caught a
  replaced settings reference that left temporary choices persisted; restoring the retained controller-owned object
  resolves it. All recorded TPS `data.json` files match baseline, with Navigator matching after normalizing only its
  existing `lastShownVersion` acknowledgement. Temporary hooks are removed, and all six owned fixtures are archived
  directly and byte-checked unchanged. No runtime data is manually overwritten and no production files are accessed.

## Limits

Physical iPhone presentation, minimum-version acceptance and production installation remain pending. Deep headers and
narrow-layout indentation are component-tested; installed QA runs on Mac. No end-to-end startup or navigation-speed
improvement is claimed. Grouping is configurable and opt-in, with no note migration.
