# TPS Notebook Navigator 7.0.7

Backward-compatible correction to New note command context. Minimum Obsidian: 1.11.0. Tested in Obsidian Plugin Test Vault and ready for the user’s BRAT pull after publication; production remains untouched.

## Changes

- Navigator's New note command follows the visible single folder, tag, or property filter after navigation has scoped the list to vault root.
- Command and toolbar share the existing facet dispatch. The existing file service still owns initial payload, manual-sort placement and GCM post-creation presentation.
- Current query text is used during debounce. Inactive search text is ignored; clearing search retains ordinary folder/root creation. Missing folders and unsupported text/composite/external-provider searches do not create an unmatched root note.
- Type-resource creation remains the toolbar's existing action. New note remains a note command. Selected/active source-note fallback and explicit new-tab intent are retained.
- No new settings, migration, cache, event listener, timer, secondary creator or delayed writer.

## Limits

This aligns the command with existing single-facet note creation. It does not add support for arbitrary searches, Type-resource commands, new template behavior or a new opening policy. No performance percentage, production or physical iPhone claim is made. The user owns the production BRAT pull after publication.
