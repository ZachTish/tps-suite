# TPS Notebook Navigator 5.5.1

## Fixed

- Properties now includes configured values found only on visible task, bullet, and heading lines.
- Effective mapped task statuses contribute to the Status values even when no redundant inline status field is authored.
  A `todo` task therefore appears under **Status → todo**.
- Authored line Status remains authoritative, duplicate values collapse, hidden source notes remain excluded, and line
  values navigate to their owning source note.

## Compatibility and validation

- Backward-compatible patch with no settings or note-data migration.
- Exact-line values require TPS Global Context Menu Entity Index v3; note-frontmatter Properties continue to work
  without GCM.
- Minimum supported Obsidian version: 1.11.0.
- Focused property-tree regression, full Vitest suite, lint, namespace and operational-identity checks, TypeScript,
  production build, artifact gates, and test-vault deployment passed.
- Tested in the isolated test vault and ready for a BRAT pull. Production was not accessed.
