# TPS Notebook Navigator 8.2.1

Backward-compatible performance fix. Ordinary body-only metadata updates no longer invalidate the selected-folder link in the mobile header, desktop title and nearest-folder-note consumer. The existing subscription compares the changed file's normalized, valid title with its prior contribution. Actual title additions/removals, ambiguous matches, cold metadata, file replacement, create/delete/rename/move and folder-note settings remain current.

No note writes, persistent index, settings migration or additional event subscriptions are introduced. A render-seeded, subscription-scoped weak title snapshot adds one initial sibling metadata pass. The next metadata callback compares against the titles used by the rendered lookup, even if the initial effect attached later. Real list sorting, property indexing and row rendering retain their own work.

## Validation

- 3,269 tests pass across 281 files under Node 24.19.0. The 51 focused cases include 18 new actual-component/hook regressions, with DOM and unrelated service contexts mocked. Both real title consumers cover metadata changes between render and effect attachment followed by a changed callback; the regression failed before the render-seeding correction.
- 1,000 siblings and 20 separately rendered unchanged body metadata events: 20,000 sibling metadata reads before, 20 changed-file reads after. A synchronous burst previously coalesced to one 1,000-read pass and now reads the 20 changed files. Initial mounting rises from 1,000 to 2,000 reads; unchanged rerenders add zero.
- Full ESLint: zero errors, 26 existing advisory warnings. Scoped formatting, TypeScript, unused strings/locales, source namespace, operational identity and built-artifact checks pass. Separate final production build deploys only shipped files to the Test vault; named reload confirms 8.2.1.
- Installed desktop-title verification temporarily enabled folder-note links in memory, with seven root Markdown siblings. Three unchanged metadata events changed whole-window metadata lookups from 19/22/23 to 6/9/10 on the initial patch and 7/9/9 after the render-seeding correction. These counts include other consumers. The window was hidden; its roughly one-second timers were background-throttled and are not UI-latency evidence.
- Test preferences were restored without saving. GCM, Controller, Health and Navigator data.json hashes remained unchanged. No new notes, production deployment, outbound automation or phone test was performed by this Navigator check.

Minimum Obsidian: 1.11.0. The release is Test-vault validated and ready for the user's BRAT pull, not a guarantee that all mobile freezing is resolved. Physical-device acceptance is separate. UI automation was unavailable in this session; the installed check exercised the existing settings publication and metadata event route, not touch gestures.
