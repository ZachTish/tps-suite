# TPS Notebook Navigator 5.14.3

This patch fixes the persistent desktop blank strip by correcting the diagnosis from the previous two releases.

## Fixed

- Rows below the list's former visible boundary now repaint when an Obsidian leaf grows or changes layout.
- Desktop virtual rows receive independent compositing layers. The mounted overscan set is small, so the correction is
  bounded to visible and nearby rows instead of promoting the complete result set.

## Changed

- Removed the desktop grid-track override from 5.14.1.
- Removed the duplicate viewport resize observer and scheduled full virtualizer remeasurement from 5.14.2.
- Restored the established flex layout and TanStack Virtual rectangle observer as the single sizing path.

## Root cause

The later rows were present in the rendered accessibility/DOM tree even while the pane showed a blank strip. That rules
out filtering, missing data, list truncation, pane height, and virtual range calculation. Electron retained the opaque
virtual scroller's previous raster boundary after the leaf changed size, so correctly mounted rows below that boundary
were not painted. The row-layer invalidation targets that failure directly.

## Compatibility and migration

- This is a backward-compatible rendering fix with no settings, note, cache, or data migration.
- Public API 3.3.0 is unchanged.
- Minimum supported Obsidian version: 1.11.0.

## Validation

- Focused virtual-row paint, list-measurement, release-note, and artifact-identity coverage passed 29 tests across four
  files.
- The full suite passed 231 test files and 2,588 tests. TypeScript, Stylelint, TPS namespace, operational identity,
  artifact identity, and the production build passed. ESLint reported 19 existing warnings and no errors.
- The final build deployed only to the isolated Obsidian Plugin Test Vault runtime. Source and runtime copies of all
  three shipped artifacts match byte-for-byte, and runtime-owned `data.json` remains present. Production was not
  modified.

## Known limitations

- UI automation is skipped while the active Obsidian window is the production vault. Source, generated CSS,
  test-runtime, and published artifacts are verified independently.
