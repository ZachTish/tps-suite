# TPS Notebook Navigator 5.6.2

## What changed

- Searching while **Checkboxes** or another built-in Type is selected now stays inside that selected Type.
- Ordinary property, status, text, tag, folder, and date filters no longer switch the list into a mixed Notes-and-Types
  result surface.
- An explicit `type:` facet remains the opt-in route for mixed-Type search results.

## Compatibility and validation

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.11.0.
- Focused selected-Type, explicit Type-facet, and list-composition regression tests passed.
- Full automated test, lint, formatting, namespace, operational identity, style, artifact, and final production-build
  gates were run.
- The final versioned artifact was deployed to the isolated Obsidian Plugin Test Vault runtime. Production was not
  touched.

This public build is ready for a user-controlled BRAT pull.
