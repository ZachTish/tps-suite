# TPS Notebook Navigator 6.2.1

Fixes **Filter tags by selection** and **Filter properties by selection** reverting to the full tree when selecting an item in the same section. Both switches now follow the selected folder, tag, or property key/value. For example, selecting a property value limits the other property values to those found on the matching notes; selecting a tag shows only tags occurring on those notes.

The switches remain independent. Empty scopes remain empty, turning a switch off restores the global tree, and existing hidden-note/descendant rules and global ordering are preserved. No migration, new setting, default change, API change, or note mutation is required. This is a backward-compatible patch to existing filtering behavior.

## Scope and handoff

Filtering follows the navigation selection, not the active note or search text. Selecting the Tags or Properties root represents all visible notes. Types keep their existing unscoped behavior.
