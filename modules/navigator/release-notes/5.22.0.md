# TPS Notebook Navigator 5.22.0

## Obsidian tag clicks in Navigator

- An exact single-tag activation from Obsidian Core now reveals TPS Notebook Navigator, selects the canonical tag, and
  dismisses an active Navigator Filter Search instead of replacing the current Core Search.
- The shared route covers rendered Markdown, Properties tag pills, Bases tag cells, Live Preview, Graph tag nodes, and
  the Core Tags pane on compatible Obsidian builds. Core queries with or without the leading `#` are normalized to the
  same Navigator tag.
- Ordinary free-text, compound-tag, malformed, non-string, synthetic, editable-input, and unactivated programmatic
  searches remain owned by Core Search. If Navigator cannot complete the route, the original Core Search call runs once
  with the same receiver and arguments.
- The capability-detected bridge follows Core Search instance replacement, covers existing and newly opened popout
  documents, suppresses stale async fallbacks, and restores only its own wrapper during unload.

This is a backward-compatible feature release. It adds no setting, public TPS API, note change, or data migration.
Minimum supported Obsidian remains 1.11.0.

Known limitation: this integration capability-detects an internal Core Search method because Obsidian exposes no public
tag-activation event. If that method is unavailable or changes incompatibly, the route fails open to Core Search. Core
Search must be enabled for Obsidian's tag controls to emit the route. An exact single-tag saved Search activated by
pointer or keyboard is also treated as a tag activation.
