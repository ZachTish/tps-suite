# TPS Notebook Navigator 6.0.0

File types replaces the former Types section in its existing sidebar position. Browse Markdown, Bases, Canvas, Drawings,
PDFs, Images, Audio and Video as whole files. No task, heading, bullet, block or web-link collections are indexed by
this replacement. File create/delete/rename events are batched without reading content.

Clicking the Properties root now shows all visible Markdown notes, including notes without properties and with
descendant display off. Child property filters, hidden-file rules, sorting and pins still apply. File categories work
even with a Markdown-only folder profile.

## Configuration and compatibility

Show File types is on by default and available in native-record mode. It replaces the old toggle. The retired Types
toggle is forced off and its creation controls are hidden. File-category IDs and ordering are reused; notes and record
data are not migrated. Note-level task progress and separately configured attached task rows remain separate features.

This major release retires structural/provider Types collections. The optional public Types capability exposes file
categories; external Type-provider registration is unavailable. Other APIs remain unchanged. Requires Obsidian 1.11.0 or
newer.

## Remaining removal candidates

The old GCM Types store/hook and Markdown structure index are disconnected from runtime consumers. Their isolated
source/tests, legacy Type-creation settings definitions, structural-row adapters, provider-Type registry implementation,
and old line-property merge helpers can be removed in a dedicated cleanup after checking shared imports. They do not
power the replacement. Keep the whole-file classifier, file selection/navigation, and ordinary property-key/value
indexing.
