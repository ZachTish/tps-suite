# TPS Notebook Navigator 5.8.0

## What changed

- The search bar now materializes the currently selected navigation property or tag before adding a structural Type
  facet.
- A selected `status = todo` value combined with Checkboxes is represented explicitly as
  `.status=todo type:structural:task`.
- Tagged and Untagged navigation selections are represented as `#` and `-#`.
- Existing navigation facets are retained without duplication, making the visible query the source of truth for the
  displayed intersection.

## Compatibility and validation

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.11.0.
- Focused tests cover property values, Untagged, idempotency, Type-facet activation, and navigation-focus preservation.
- Full automated test, lint, formatting, namespace, operational identity, style, artifact, and final production-build
  gates were run.
- The final artifact was deployed only to the isolated Obsidian Plugin Test Vault runtime; production was not touched.

This public build is ready for a user-controlled BRAT pull.
