# TPS Notebook Navigator 5.7.1

## What changed

- Fixes `.status=todo` and other property selections returning no rows when **Checkboxes** or another structural Type is
  selected.
- Property clauses no longer eliminate source notes before their structural rows are examined.
- Each row is matched against its effective line and owning-note properties using that Type's configured inheritance
  mode. With the default line-first mode, canonical task status wins over a conflicting note-level status.
- Positive and negative property clauses are both applied to structural rows.

## Compatibility and validation

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.11.0.
- Focused structural-search and provider-row regressions cover canonical checkbox status plus note-property conflict.
- Full automated test, lint, formatting, namespace, operational identity, style, artifact, and final production-build
  gates were run.
- The final artifact was deployed only to the isolated Obsidian Plugin Test Vault runtime; production was not touched.

This public build is ready for a user-controlled BRAT pull.
