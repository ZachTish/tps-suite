# TPS Notebook Navigator 5.6.1

## What changed

- Fixes built-in Type collections showing a populated navigation count but an empty list after selection.
- Checkboxes, Bullets, Headings, and the other built-in Types now read rows from the same direct shared index
  subscription used by their actions.
- External provider-owned Types continue to use the aggregate provider API.

## Compatibility

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.11.0.

## Validation

- Added focused snapshot-routing coverage for built-in and external provider Types.
- Ran the full automated test, lint, formatting, namespace, operational identity, style, artifact, and production-build
  gates.
- Deployed the final versioned artifact to the isolated Obsidian Plugin Test Vault runtime.
- Live UI automation was skipped because the active Obsidian window was the production vault, which was not authorized
  for access.

This public build is ready for a user-controlled BRAT pull.
