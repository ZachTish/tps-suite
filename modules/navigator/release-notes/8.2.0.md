# TPS Notebook Navigator 8.2.0 — Wildcard hidden-property rules

The **Hide notes with property rules** vault-profile setting now accepts one `*` at the start or end of a value. `kind=transaction*` or `kind: transaction*` hides notes with nested kinds such as `transaction/financial/investment`; `kind=*example` hides values ending in `example`. `kind=transaction/*` targets descendants without also matching bare `transaction` or `transactional`. Scalar and list values use the same case-insensitive matching. Exact `key=value` and key-only rules are unchanged. Rules still hide notes in Navigator and do not rewrite frontmatter.

This is a backward-compatible feature release with no new setting, schema migration, file writer, or vault scan. The existing mobile and desktop settings control is used. Only a single leading or trailing wildcard is supported; a bare `*`, multiple wildcards, and mid-value wildcards are ignored. A broad prefix such as `transaction*` also matches `transactional`. Minimum Obsidian remains **1.11.0**.

## Validation

- All **3,251 tests across 280 files** passed. Focused cases cover nested list values, case folding, prefix/suffix and descendant-only rules, colon/equals equivalence, preserved exact/key-only rules, and invalid patterns. A 1,000-file metadata-only indexing check made 1,000 metadata lookups and **zero** raw reads, cached reads, or write attempts.
- Full ESLint passed with zero errors and 26 existing advisory warnings. Style lint, TypeScript, locale/string, TPS namespace, artifact, operational-identity, and targeted formatting checks passed. A separate production-mode build deployed the tested `main.js` and `manifest.json` to the Obsidian Plugin Test Vault; the final build was byte-identical.
- In the foreground test vault on Obsidian 1.14.4, the old 8.1.0 runtime displayed all three synthetic notes even with `kind=transaction*` configured. After loading 8.2.0, that rule hid the nested transaction note. Adding `kind: *example` hid the suffix note while the unrelated control stayed visible. The updated settings copy and 8.2.0 About version were visible. The original empty rule list, hidden-items visibility, and search were restored; the three QA notes were moved directly from Inbox to `_archive` with bytes preserved. The plugin's runtime `data.json` was not replaced by deployment. Physical iPhone behavior was not separately tested.

This release was tested in the test vault and is ready for the user's BRAT pull. Publication does not imply a production installation.
