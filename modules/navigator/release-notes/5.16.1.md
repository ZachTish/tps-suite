# TPS Notebook Navigator 5.16.1

This backward-compatible patch makes navigation-scope clicks leave Filter Search predictably instead of combining a
newly selected base with stale search state.

## Navigation and search

- An ordinary folder, tag, property, or Type selection now dismisses the complete search surface, clears both immediate
  and debounced query state, and resets the temporary whole-vault search scope before the new selection becomes the list
  base. The rule covers the navigation tree, keyboard selection, pickers, mobile ancestor breadcrumbs, clickable folder
  group headers, tag/property pills, and explicit Reveal-in-folder actions from toolbars, rows, and context menus.
- Folder, tag, property, and note navigation shortcuts follow the same reset rule when they reveal or select a new
  scope.
- Existing Shift and configured modifier gestures still add tag, property, or structural Type facets to the current
  query without changing the navigation selection or dismissing Search.
- Context-menu creation also resets Search when it changes the selected target scope. Expansion chevrons, opening
  context menus, alternate-tab opens, property links, and saved-search shortcuts remain independent from this reset.
- Failed or stale navigation attempts leave the active search intact.

## Compatibility

- Patch release with no settings or note-data migration.
- Minimum supported Obsidian version remains 1.11.0.
- TPS Notebook Navigator remains co-installable with upstream Notebook Navigator.
