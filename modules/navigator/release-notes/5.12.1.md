# TPS Notebook Navigator 5.12.1

This patch completes the all-resources vault-root contract by adding the canonical structural collections, not only
files and attached tasks.

## Fixes

- The vault root now includes Checkboxes, Bullets, Headings, Code blocks, Callouts, Blockquotes, Tables, and Web links
  in labeled sections after the visible file list.
- Structural rows use the same visibility-filtered snapshots, guarded source actions, task completion, and context menus
  as their dedicated Type views.
- When canonical Checkbox rows are available, the optional attached GCM task feed is suppressed at root so the same task
  is not rendered twice.
- When canonical Checkboxes are unavailable, the attached task feed remains available as a compatibility fallback.

## Validation

- Focused root catalog-selection and task-provider deduplication tests.
- Full Vitest, ESLint, Stylelint, TypeScript production build, TPS namespace/artifact gates, operational-identity gate,
  and atomic test-vault runtime deployment.
- Minimum supported Obsidian version: 1.11.0.
- Visual automation was intentionally skipped because the active Obsidian window was the production vault, not the
  isolated test vault.

Tested through the Obsidian Plugin Test Vault build/deployment pipeline and ready for the user's BRAT pull. The release
does not directly install or reload the production vault.
