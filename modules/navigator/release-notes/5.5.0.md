# TPS Notebook Navigator 5.5.0

## Structural line-property inheritance

- Checkboxes, Bullets, and Headings now sort and group by their exact line properties by default, inheriting the owning
  note only when the line has no value.
- The Sort/Group menu now offers note-first, line-first, and combined inheritance modes. The selection is saved per
  structural Type.
- Combined mode includes distinct note and line values in one deterministic value/group label.
