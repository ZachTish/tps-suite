# TPS Notebook Navigator 4.9.1

## Intent

Make public menu extensions honor their synchronous contract without changing native `MenuItem` timing or allowing an
invalid Type-only menu to appear partially constructed.

## Changes

- A Promise-returning Type builder now invalidates the complete attempted menu even when it synchronously adds an item
  before returning its Promise.
- A Type builder that throws after committing a partial item, or an item initializer that throws or returns a Promise,
  also suppresses the complete Type-only menu. Rejected Promises are observed and delayed additions remain ignored.
- Every public `addItem(...)` initializer still runs immediately, exactly once, with the real Obsidian `MenuItem` before
  `addItem(...)` returns, preserving submenu capture, object identity, and existing integrations.
- File, folder, tag, and property hooks remain composed with Navigator-owned actions. Already-committed synchronous
  items remain counted for correct separator placement if their builder later violates the contract; Obsidian exposes no
  supported API for retracting a committed native item.
- Registering the same file, folder, tag, property, or Type callback multiple times now creates independent
  registrations. Each disposer remains idempotent and removes only its own registration.

## Compatibility and migration

- Backward-compatible patch release; public API remains 2.10.0.
- Minimum supported Obsidian version remains 1.11.0; mobile remains supported.
- No settings, callback state, note data, or migration is added.

## Validation

- Focused regressions cover immediate exact native-item delivery, partial throwing builders, resolved and rejected
  Promise builders, throwing and Promise-returning item initializers, delayed additions, duplicate registration
  lifetimes, native composed-menu item counts, and Type event consumption/display.
- The complete suite passes: 208 Vitest files and 2,240 tests, plus Prettier, ESLint, TypeScript, stylesheet,
  source-namespace, artifact-identity, and production-mode build gates.
- Live Obsidian 1.12.7 QA in the isolated Plugin Test Vault confirmed the 4.9.1 release panel and visible Types
  hierarchy. With a healthy action and a Promise-returning action registered together, right-click did not open or
  consume the Type menu and logged the synchronous-contract error. Disposing only the invalid registration immediately
  restored the healthy action; disposing the remaining registration removed it again. All temporary registrations and
  globals were removed.
- The deployed test runtime is byte-identical to the release artifacts. Runtime-owned `data.json` retained inode
  `232880478`; only its normal `lastShownVersion` field advanced to 4.9.1 during the verified reload.

## Known limitations

- Menu builders and item initializers must stay synchronous. Put asynchronous work inside `onClick` handlers.
- Obsidian provides no supported removal API for a native `MenuItem` already committed to a composed file, folder, tag,
  or property menu. TPS logs and observes a late contract violation but preserves the host menu and its synchronous
  actions.
