# TPS Notebook Navigator 5.13.0

This release adds native Base and Canvas creation directly to their file-backed Type views.

## New

- **Bases** now shows a **New base** control when Obsidian's Bases core plugin is enabled.
- **Canvas** now shows a **New canvas** control.
- Each control uses the matching database or canvas icon.

## Behavior

- Creation reuses the same `FileSystemService` operations used by folder context menus, including valid initial content,
  collision-safe names, opening, native rename, and error handling.
- Because a Type collection is vault-wide and has no selected folder context, the new resource is created at the vault
  root and immediately selected in the Type list.
- No settings or data migration is required.

## Validation

- Focused file-backed Type creation routing and label tests.
- Full Vitest, ESLint, Stylelint, TypeScript production build, TPS namespace/artifact gates, operational-identity gate,
  and atomic test-vault runtime deployment.
- Minimum supported Obsidian version: 1.11.0.
- Visual automation was intentionally skipped because the active Obsidian window was the production vault, not the
  isolated test vault.
