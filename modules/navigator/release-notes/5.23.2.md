# TPS Notebook Navigator 5.23.2

This patch restores live GCM-generated note icons and colors on installations that leave authored frontmatter metadata
disabled, and adopts the shared TPS template-tag lifecycle for Navigator-created notes.

- Authored `icon` and `color` values remain gated by **Use frontmatter metadata**.
- Explicit Notebook Navigator file appearances remain authoritative.
- GCM's read-only presentation overlay is now evaluated independently as the final icon/color fallback, so its provider
  revisions can repaint mounted file rows, note shortcuts, and Recent Notes without writing YAML.
- With TPS Global Context Menu 1.50.0 or newer, folder-note, Daily Note, and Navigator-calendar template copies remove
  only the exact top-level `template` tag before creation and verify it again after Templater. Other YAML tags, their
  order, and body `#template` text are preserved; the source template is never changed.
- Automatic Navigator SVG icon-reference repair skips a source currently protected by the shared template guard.
  Explicit user appearance edits remain available.
- No setting, IndexedDB schema, or Notebook Navigator public API changes. Minimum supported Obsidian: 1.11.0.
- Known limitations: generated values still require a compatible GCM provider and matching icon/color destination names;
  the template lifecycle requires GCM 1.50.0 or newer and intentionally does not rewrite old notes retrospectively.

Validation passed 256/256 test files and 2,943/2,943 tests, TypeScript, diff checks, and the mandatory separate
production-mode build. After a cold reload, Obsidian 1.13.7 loaded Notebook Navigator 5.23.2 beside GCM 1.50.0. With
**Use frontmatter metadata** disabled, a GCM-generated magenta sparkle appeared on the mounted note row, disappeared and
returned after live property changes without a reload, and remained correct after the cold reload. The shared Daily Note
lifecycle removed only the exact marker while preserving unrelated tags and body content; the source stayed
byte-identical. Temporary notes were archived, the QA rule was disabled, outbound automation remained off, and
production was not accessed. This release is ready for a BRAT pull after publication.
