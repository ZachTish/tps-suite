# TPS Notebook Navigator 5.18.2

TPS Notebook Navigator `5.18.2` fixes the persistent blank lower region in a popped-out Navigator list after the leaf
grows.

## Root cause and fix

- The pane, panel, and scroller already had the correct full-height CSS contract. The blank area was TanStack Virtual's
  stale viewport range rather than a clipped footer or missing bottom padding.
- `ItemView.onResize()` sent its authoritative recovery event through the application's global `window`, while the
  virtualizer correctly listened on the scroll element's `ownerDocument.defaultView`.
- In an Obsidian popout those are different windows. After the bounded startup sampler ended, a later leaf resize
  therefore never reached the virtualizer, which continued mounting rows only through its old, shorter boundary.
- The resize bridge now resolves the Navigator container's owner window, creates the `CustomEvent` in that same browser
  realm, and dispatches it there. The normal single-window path is unchanged.

## Compatibility

- Backward-compatible rendering fix; no settings, CSS, public API, note data, or migration changed.
- Minimum supported Obsidian version remains `1.11.0`.
