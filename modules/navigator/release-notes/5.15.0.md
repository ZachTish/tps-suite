# TPS Notebook Navigator 5.15.0

This backward-compatible minor release merges the public Notebook Navigator 3.3.3 release (`7ae7db62`) into the
co-installable TPS fork.

## Included upstream improvements

- Adds per-location appearance controls for file tags, properties, task progress, and text counts.
- Adds the upstream sort/group default overhaul and `follow` group order, calendar outside-month-day display,
  configurable unfinished-task icons, safer new-note property creation, and calendar/renamed-view fixes.
- Refreshes settings organization, localization, task display, pinned handling, dependencies, documentation, and
  generated style validation from the public upstream release.

## TPS compatibility and migration

- Preserves the TPS plugin, view, command, DOM/CSS, event, drag, local-storage, IndexedDB, and settings-transfer
  namespaces, so TPS Notebook Navigator remains co-installable with upstream Notebook Navigator.
- Preserves structural Types, Global Context Menu/provider integrations, one-way read-only upstream-settings import, and
  TPS Type settings. The new appearance model retains line-property inheritance, multi-value grouping, and no-value
  placement for TPS Type appearances.
- Adds `property-follow`, `property-day-follow`, `line-property-follow`, and `line-property-day-follow` to the additive
  TPS public API 3.4.0.
- Existing settings need no manual migration. The synced What's New marker uses a TPS-namespaced local high-water mark
  to avoid repeating already-shown notes on another device.
- Minimum supported Obsidian version: 1.11.0.

## Scope and limitation

- This release includes public upstream `main` through the released 3.3.3 tag. It intentionally excludes upstream's
  unreleased `3.3.4-1` side branch.

## Validation

- TypeScript, ESLint, Prettier, Stylelint, locale consistency, TPS source namespace, operational identity, and generated
  artifact checks passed.
- The complete suite passed: 236 test files and 2,695 tests.
- The final production build deployed only to the isolated Obsidian Plugin Test Vault. `main.js`, `manifest.json`, and
  `styles.css` byte-match the deployed runtime, while runtime-owned `data.json` was preserved unchanged.
- In Obsidian 1.13.6's test vault, TPS Notebook Navigator was reloaded independently and its settings hub rendered the
  TPS integration destination alongside the merged upstream configuration destinations. Upstream Notebook Navigator
  remained separately installed.
- Production was not accessed or modified.
