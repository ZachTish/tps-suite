# TPS Notebook Navigator 5.8.4

## What changed

- Makes Checkboxes rows visually match normal note rows, with the leading file icon replaced by the task checkbox.
- Task title/source, checkbox, and More actions controls now use file-row-specific resets that override ordinary
  Obsidian/theme button chrome.
- Removes inherited control fills, borders, shadows, and native button appearance while retaining normal row hover,
  focus, and selection feedback.
- Wrapping, metadata, completion, context menus, and touch targets are unchanged.

## Compatibility and validation

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.11.0.
- Focused Type-row, TypeScript, formatting, and stylesheet gates passed.
- Full automated test, lint, formatting, namespace, operational identity, style, artifact, and final production-build
  gates were run.
- The final artifact was deployed only to the isolated Obsidian Plugin Test Vault runtime; production was not touched.

This public build is ready for a user-controlled BRAT pull.
