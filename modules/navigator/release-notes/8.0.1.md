# TPS Notebook Navigator 8.0.1 — Keep body-only edits out of navigation work

An Obsidian metadata-cache update for an ordinary note previously invalidated Navigator's folder-name cache, bumped
folder-note exclusions, and scheduled another scoped tag/property selection rebuild, even when the note's title and
indexed metadata had not changed. This patch compares the changed file with the observed active folder note before
invalidating folder state. The metadata event no longer bumps the scoped file-selection version; IndexedDB
content-change notifications already refresh real tag, property, configured display-name, and folder-style changes.

Folder-note title changes that make another note active, remove an active note, or create an ambiguous match still
refresh folder visibility and labels. Creation, deletion, and rename retain their file-change refresh path. There are no
settings, schema, migration, writer, timer, or minimum-Obsidian changes. Minimum supported Obsidian remains **1.11.0**.
This backward-compatible performance fix is a patch release.

## Validation

- A red regression showed 20 body-only metadata events on an ordinary note caused 20 folder-display-name notifications.
  After the fix, the same burst causes zero notifications and zero folder-note lookups. Twenty body-only events on an
  active folder note also cause zero navigation bumps; unchanged metadata events cause zero scoped file-selection
  version bumps.
- Focused tests cover title-based folder-note identity addition and removal, a same-path title display-name update
  through the existing IndexedDB owner, and real tag/property changes. All **3,213 tests in 274 files** pass.
  TypeScript, TPS namespace, artifact identity, and operational-identity checks pass. ESLint has zero errors and 26
  existing advisory warnings.
- The separate final 8.0.1 build deployed `main.js` and `manifest.json` into **Obsidian Plugin Test Vault**. The runtime
  `main.js` matched the tested source artifact. A guarded app reload was needed because Obsidian retained 8.0.0 in
  memory after a scoped disable/loadManifest/enable sequence; after reload, the in-memory manifest and loaded plugin
  both reported 8.0.1.
- In Obsidian 1.14.4 on Mac, the installed Navigator selected `Inbox` and showed its scoped note list. A short edit in
  the 1,500-paragraph synthetic typing note appeared immediately and was undone. The note's SHA-256 remained
  `e8035e0cc6ecd1f67bffc1c954df85e5e876b99de89f2659193247117a715217`. Navigator's runtime `data.json` was not
  overwritten by the build; dismissing its release notice advanced the existing `lastShownVersion` marker to 8.0.1.
- In the combined foreground Test-vault check with the other active plugin fixes installed, 24 typed keys saved
  correctly. The per-call median/max was 15/58 ms versus the earlier 11/64 ms baseline; small/large note-switch AX
  settle was 1,054/1,079 ms versus 1,078/1,059 ms. System and automation load dominated these samples, so they do not
  establish a reliable end-to-end latency change. No content or navigation regression was observed.

Physical-iPhone behavior and production speed have not been measured here. This release is tested in the Test vault and
ready for the user's BRAT pull; production installation is separate.
