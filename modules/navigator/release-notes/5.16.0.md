# TPS Notebook Navigator 5.16.0

This backward-compatible minor release keeps the experimental Types implementation available while pausing its
development and making the ordinary navigator note/file-focused by default. It also hardens Filter Search, saved-search
execution, and per-note task-progress indexing.

## Types containment

- Adds **TPS integration → Types collections (paused) → Enable Types collections (experimental)**, off by default.
- Keeps all Types source code, public API, provider contracts, saved ordering, per-Type appearances, and item-creation
  preferences. No Types capability or stored preference is deleted.
- Runs one bounded upgrade migration that disables Types collections and individual GCM task rows once. It preserves
  Type preferences and every standard task-progress setting; a later explicit Types opt-in persists across reloads and
  sync.
- Hides Type item-creation controls while Types are off without clearing their values.
- Cancels pending work, detaches subscriptions, and clears exact-line, Markdown-structure, Web-link, and GCM hydration
  snapshots when Types are disabled. Properties remains note-frontmatter-only.
- Uses a stable empty row-provider scope when no provider is enabled, avoiding a linear walk over every visible note.

## Task progress

- Standard note task-progress bars and counts remain available while Types and individual GCM task rows are off.
- Oversized task-bearing notes retain their last-known counts, or remain unknown on first index, instead of being
  reported as `0 / 0`.
- Transient read or parse failures preserve the prior value and remain retryable; a later successful pass publishes the
  exact recovered count.

## Search and navigation reliability

- Incomplete or unsupported filter-shaped terms fail closed with an invalid input state, an accessible visible
  explanation, and no results. Invalid Filter Searches cannot be saved as shortcuts.
- Name-only searches keep `AND` and `OR` as ordinary filename/alias words. Connectors combined with structured criteria
  must form a complete supported tag/property expression; unsupported mixed expressions fail closed instead of silently
  changing meaning.
- `type:` facets fail closed with a specific explanation while Types collections are disabled.
- Calendar date selection preserves every unrelated text/filter facet and negative date clause. Relative date ranges
  refresh after local midnight or app resume, and file modifications refresh all active date queries regardless of sort
  mode.
- Saved searches preflight exact folder, tag, and property start targets before changing navigation, provider, or query
  state. A deleted or renamed target leaves the current view untouched and displays a warning.

## Compatibility and migration

- Semantic version: minor, because the release adds an experimental containment setting and a one-time default migration
  while preserving the existing Types API, configuration schema, and all note data.
- Minimum supported Obsidian version: 1.11.0.
- TPS Notebook Navigator remains co-installable with upstream Notebook Navigator. Upstream settings import remains
  explicit, one-way, and read-only with respect to upstream state.
- Production is outside this validation and release workflow and must not be accessed or modified.
