# TPS Notebook Navigator 8.2.2

Backward-compatible performance patch. Unmeasured standard file rows skip record
and drawing metadata lookups only when those values cannot change their height.
The existing geometry calculator compares no-image, image and missing-image
layouts before taking the shortcut. No pixel values or layout arithmetic are
duplicated.

## Scope and compatibility

- The shortcut requires an unpinned standard file row with images enabled,
  previews/tags/property rows/task progress disabled, and an existing date or
  parent-folder line. All three image-state estimates must be identical.
- Actual title measurement still resolves current metadata. Short measured
  titles can remain sensitive to drawing status even when their unmeasured
  maximum estimate is not: the desktop regression retains 55 → 58 → 55 pixels
  as a same-mtime drawing flag is added and removed. This is test geometry, not
  a new hardcoded runtime size.
- Pinned/compact rows, previews, pills, task progress, image-sensitive metrics,
  missing date/parent lines, provider rows and spacers keep their existing paths.
  Drawing flag truthiness, companion-image selection and rendering are unchanged.
- The virtualizer still rebuilds unmeasured tails when its existing owners
  invalidate them. This patch removes avoidable per-row lookups inside eligible
  estimates; it does not remove those invalidations.
- No cache, persistent index, timer, listener, writer, settings/schema change or
  migration is introduced. Minimum Obsidian remains 1.11.0. Desktop and mobile
  retain the same feature support.

## Validation

- The source-level focused run passes 117 tests across four files under Node
  24.19.0, including 27 new tests. The new harness executes the actual hook's
  estimate and measurement callbacks and the actual TanStack Virtualizer;
  React effects, DOM and unrelated service contexts are mocked.
- Before the source correction, nine of the initial 21 regression cases failed
  as expected; the 12 controls passed. Six further boundary controls were added
  before the final focused run.
- A 1,000-row comparison runs six measured-tail changes through both the
  unchanged live resolver and the shortcut. Metadata lookups fall from 6,554
  to zero, and record lookups independently fall from 6,554 to zero. Every row's
  key, start, size and end, plus total size, match across seven snapshots.
  Reference lookups are counted separately from the shortcut.
- Coverage includes desktop/mobile and fractional/custom metrics, the exact
  image-height boundary, absent/present images and drawing companion images,
  date-only and tag/property parent lines, root notes, descendants disabled,
  same-folder rows, pinned/compact rows, preview/tag/property/task controls and
  live same-mtime Excalidraw/Tldraw changes in measured titles.
- Scoped ESLint, source TypeScript (`--noEmit --skipLibCheck`), source/test
  formatting and `git diff --check` pass. Independent source/test review found
  no blocking issue.

- All 3,296 tests in 282 files pass under Node 24.19.0. Full ESLint reports zero
  errors and 26 existing advisory warnings. Namespace, artifact and operational
  identity checks pass. The separate production-mode build passes TypeScript
  and locale checks and deploys only runtime artifacts to the Test vault.
- The targeted Test-vault reload confirmed 8.2.2. An installed comparison with
  GCM 7.3.8 and Health 4.2.3 used the existing Navigator virtualizer and three
  display-only Daily Macros/Activity fixtures, including repeated tab switches
  and remounts. Two observed 8.2.1 unmeasured-tail rebuilds each made 14,350
  metadata lookups (23.9/24.3 ms inside the synchronous measurement call); the
  observed 8.2.2 rebuild made seven (5.6 ms). The list contained about 15,400
  items. Rebuilds occurred in different tab phases and the window was hidden
  and unfocused, so these observations support reduced per-rebuild work, not
  an end-to-end interaction or physical frame-time improvement claim.
- All six repeated Live Preview tab checks retained connected macros/activity
  widgets. Both installed runs completed without navigation mutation attempts
  or Health render errors. Settings stayed unchanged, temporary observers were
  removed, prior navigation was restored, and all three fixtures from each run
  were byte-checked and moved directly to `_archive`.
- A final documentation-only rebuild retained the same artifact hashes. No
  settings, credentials, runtime state or production files are released.

## Evidence boundaries

The focused counts prove removal of unnecessary work, not physical frame or
interaction latency. No physical iPhone/Windows or production validation is
established by these tests. Production installation is a separate, user-owned
BRAT pull; publication alone does not establish that any device installed it.
