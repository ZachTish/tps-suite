# TPS Notebook Navigator 4.7.1

## Intent

Make the first-class Types browser truthful and easy to discover: every visible built-in entity should be reachable, and
an upgraded vault should not bury the Types section beneath an older saved navigation order.

## Changes

- Removes the external-provider 1,000-row ceiling from built-in Notes, Checkboxes, Bullets, Headings, and dynamic GCM
  Kind collections. Their displayed count and virtualized row set now describe the same complete visible collection.
- Keeps external Type owners and augmenting row providers under the existing shared 1,000-row safety ceiling. Owner rows
  remain first, and duplicate public row identities remain de-duplicated with the owner winning.
- Inserts a missing Types section immediately after Folders when normalizing a legacy saved navigation order. Existing
  custom Types placement and every other valid user-ordered section remain unchanged.

## Compatibility and migration

- Backward-compatible patch release; no settings, API, or note-data migration.
- Public API remains 2.8.0.
- Minimum supported Obsidian version remains 1.11.0.
- Built-in Types still respect the active Navigator profile and hidden-item rules, and still require a compatible TPS
  Global Context Menu Entity Index v3.

## Validation

- Focused regressions cover more than 1,000 rows for Notes, Checkboxes, Bullets, Headings, and GCM Kinds; the separate
  external-provider ceiling; owner-first composition; duplicate identities; legacy and customized root orders; malformed
  saved orders; and reorder normalization.
- The complete test suite, formatting, ESLint, TypeScript, stylesheet, source namespace, final artifact, and
  production-mode build gates pass for the released artifact.
- Live Obsidian 1.12.7 test-vault QA confirms Types after Folders, a 12,766-item Bullet collection, and exact-line
  Bullet activation from that collection. Focused adapter and row tests retain note, checkbox, heading, and Kind
  activation coverage.

## Known limitations

- Built-in Types intentionally exclude sources hidden by the active Navigator profile or hidden-item rules.
- Missing, disabled, incompatible, or incomplete TPS Global Context Menu indexing fails closed with a visible status
  row.
- External Type-provider rows remain capped at 1,000 per composed collection as a public-provider safety guard.
