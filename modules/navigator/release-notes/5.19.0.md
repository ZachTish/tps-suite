# TPS Notebook Navigator 5.19.0

This backward-compatible minor release adds an opt-in real-file-only native-record profile. Virtual line/Types rows,
attached task rows, and companion-property writes are disabled in that profile; the compact file navigator and typed
Markdown property drops remain available.

Minimum Obsidian: 1.11.0.
