# TPS Notebook Navigator 5.17.0

TPS Notebook Navigator `5.17.0` makes GCM-defined property types authoritative for file drops and accepts guarded
multi-task drops from GCM TPS List/Table selections.

## Typed property drops

- File drops onto Navigator property values resolve the corresponding GCM definition when `itemProperties` v1 is
  available.
- List, link-list, and tag-list fields add and deduplicate instead of replacing existing members. Scalar fields retain
  replacement semantics.
- Markdown files use GCM's frontmatter mutation API; supported Canvas, Base, PDF, media, and other non-Markdown files
  use GCM's companion-property API without changing source bytes.
- No-op list additions are reported as skipped rather than successful updates. Without a compatible GCM definition, the
  existing Markdown-only assignment path remains unchanged.

## GCM task selections

- One or more selected task rows dragged from GCM TPS List or TPS Table can be dropped on a Navigator tag or concrete
  property-value row.
- Navigator validates the transient exact task references, resolves the configured GCM field, chooses additive or
  replacement semantics from its type, and delegates the mutation back to GCM with direct-user provenance.
- Stale task lines, incompatible APIs, hidden/non-inline properties, Folder/Kind fields, and empty property keys fail
  closed with a notice.

## Compatibility and known limitations

- Backward-compatible minor release with no settings or note-data migration.
- Multi-task pointer drops are desktop-only and deliberately exclude folder targets and empty property-key rows.
  Ordinary file multi-drag remains available on folders, tags, and properties.
- Requires TPS Global Context Menu `1.32.0` for typed task-line drops. Existing Navigator behavior remains available
  when GCM is absent or incompatible.
- Minimum supported Obsidian version remains `1.11.0`.
