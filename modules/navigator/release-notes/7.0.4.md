# TPS Notebook Navigator 7.0.4

Tested in Obsidian Plugin Test Vault and ready for the user's BRAT pull. This release does not establish production installation or native-equivalent performance.

This backward-compatible patch avoids repeated provider enumeration and flag parsing for ordinary Markdown notes while scrolling. The classifier checks current frontmatter for drawing-key presence and reuses existing filename detection before entering the provider loop. All present flag values—including null, empty and unusual values—still use the original truthiness rules. Filename drawings, excluded drawings and companion-image behavior remain unchanged.

Obsidian metadata is still read live. Same-mtime metadata changes are visible immediately while Navigator's existing property-index updates are buffered. There is no new cache, state, observer, timer, setting, writer, repair, migration or public API. Variable title heights remain supported. Minimum Obsidian remains 1.11.0; desktop and mobile remain supported.

## Validation

- The actual TanStack Virtualizer regression uses 1,000 notes and 24 title-size changes. Ordinary-note provider flag checks change from 18,400 to zero, with exact total and row geometry preserved against the full provider path. Live metadata lookup counts remain unchanged.
- The actual storage metadata-event handler regression covers both drawing keys during its pending 100ms buffer at unchanged file mtime. Cold/stale/reset data, filename renames, all flag values, excluded drawings, missing/theme-specific companion images and content/settings changes are covered.
- The 58 focused checks and full 3,180 tests in 275 files passed. Full ESLint reported zero errors and the same 24 existing advisory warnings. Source TypeScript, locale, namespace and artifact/operational-identity checks passed.
- The versioned artifact was built, deployed and Navigator reloaded only in Obsidian Plugin Test Vault. The mandatory separate final production build after documentation updates verified byte-identical artifacts.
- After dismissing accumulated release dialogs, visual inspection of the live Navigator list and a page scroll down/up showed correct row/title/path spacing, without observed overlaps or blank rows. Closing the dialogs advanced only the existing `lastShownVersion` marker from 7.0.1 to 7.0.4; all other Navigator settings were unchanged.

Installed test-vault CPU comparison on 2026-09-27 used two 24-step programmatic scroll captures per version. GCM 3.6.5, the 426px list width and the focused foreground window were unchanged. Each capture followed a Navigator reload and five seconds of settling.

| Sampled CPU time, mean of two captures | 7.0.3 | 7.0.4 |
| --- | ---: | ---: |
| Active work | 995.7 ms | 866.2 ms |
| Drawing-provider inclusive | 344.3 ms | 239.5 ms |
| Provider-loop inclusive | 170.8 ms | 62.8 ms |
| Row estimate inclusive | 481.0 ms | 424.5 ms |
| Virtualizer measurement inclusive | 524.2 ms | 466.2 ms |

Inclusive times overlap and must not be added. Mean sampled active work decreased about 13%, and drawing-provider work decreased about 30%. Release-note overlays were present during these captures, so this is programmatic profiling of the underlying installed list, not unobstructed user-scroll testing. Paint medians changed from 54.65/53.0 ms to 50.5/53.2 ms; neither version recorded PerformanceObserver long tasks. These small samples show a targeted CPU reduction, not a strong visible-latency improvement or native-Obsidian acceptance.

The generic virtualizer tail loop and live metadata lookups remain. This release does not establish cold-start, production or physical iPhone performance. Production installation remains the user's BRAT pull.
