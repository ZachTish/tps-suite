# TPS Notebook Navigator 7.0.8

Backward-compatible patch removing the unnecessary 100 ms typing delay when search becomes empty. Minimum Obsidian: 1.11.0. Tested in Obsidian Plugin Test Vault and ready for the user's BRAT pull after publication. Production remains untouched.

## Changes

- Clearing search immediately releases the applied filter using the existing effect. The Clear search button, keyboard activation and deletion of the final character share this path.
- Normal nonempty typing retains its 100 ms debounce. Existing effect cleanup cancels pending text so clearing cannot restore an obsolete query.
- Search focus and root-scoped navigation remain unchanged. No new state, cache, listener, timer, setting, API or migration.

## Validation

- Nine real-hook state/effect regressions cover name/tag/property clearing, cancellation, typing bursts, repeated empty actions, subsequent typing, deactivation and unmount. Five fail against the preceding implementation. Browser timers are fake; unrelated context services and the midnight clock are mocked.
- All 3,231 tests in 277 files pass under Node 24.19.0/npm 10.9.2. Full ESLint reports zero errors and 24 existing advisory warnings. The first lint run found test-only unsafe calls, corrected before rerunning lint and the full suite. Stylelint, scoped formatting, TypeScript, locale, namespace and artifact/operational-identity checks pass.
- Separate normal build deployed to the test vault; explicit named plugin reload confirmed 7.0.8. Final documentation rebuild retained identical artifacts, matching the test runtime.
- Actual foreground name/tag/property search and Clear search gestures in Obsidian 1.14.2 preserved search focus, exact fixture content and the complete result set. Matching clear timings changed from 188.1/184.5/167.5 ms to 90.6/66.0/64.4 ms. Nonempty typing after its final input stayed comparable: 270.9/129.0/143.3 ms before, 262.5/132.5/139.5 ms after.
- All six after actions recorded zero mutation events and no observed long tasks. Filtered results contained exactly three fixtures; clearing restored all 11,371 file rows. Consumers stayed enabled; outbound automation was not enabled. Hooks were removed, fixtures archived and prior note/search restored. Five settings files were byte-identical during QA; across reload Navigator changed only its normal lastShownVersion acknowledgment.

## Limits

Readiness is two animation frames observing expected DOM rows, not compositor paint. These small samples establish the targeted delay removal, not cold-start, production, physical iPhone or native-performance parity. Initial name indexing and full-list row estimation still perform substantial metadata work. This release does not claim to fix every naming or navigation delay.
