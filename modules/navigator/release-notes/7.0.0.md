# TPS Notebook Navigator 7.0.0

Navigation now searches from the vault root. Clicking a folder, tag, property or Type places its criterion in the visible search field; clearing search shows the whole visible vault. Folder subtree searches use `folder:"/Projects/**"`. Saved start locations become visible search terms. Single-facet searches retain their existing New note behavior, and keyboard/tree focus follows the clicked item.

This is a major version because selection/list API snapshots and sort/appearance scope now report/use the root. Existing per-scope preferences remain stored. Hidden-item preferences still apply. No note migration or new persisted setting is added. Minimum Obsidian: 1.11.0.

Validation in Obsidian Plugin Test Vault: 3,143 tests across 271 files passed; ESLint passed with 24 existing warnings and no errors; namespace, operational identity, artifact identity, TypeScript and locale/build checks passed. A separate final production build deployed only the test runtime, followed by targeted reload. Installed QA verified folder/tag/property/Type searches, clearing and erasing queries, root recursion, direct-child folder searches, saved start constraints, and actual UI tag-based note creation. Final reload confirmed root scope, recursive folder query, three fixture results and the selected tree row. Original settings were restored and fixtures archived. Physical iPhone acceptance remains outstanding.

Tested in the test vault and ready for the user’s BRAT pull. Not installed in production.
