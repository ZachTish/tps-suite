# TPS Notebook Navigator 7.0.12 — Skip hidden icon metadata work

Compact file rows were looking up drawing frontmatter even though compact mode does not show feature images. Mounted rows now inspect drawing metadata only when the effective appearance shows images. Mobile rows and other rows without native dragging also stop resolving the desktop drag-preview fallback icon. Draggable desktop rows, standard-mode drawing thumbnails, and live Excalidraw/Tldraw frontmatter detection retain their existing behavior.

This is a backward-compatible performance patch with no setting, stored state, listener, cache, writer, or migration. Minimum supported Obsidian remains **1.11.0**. It was installed and tested only in the isolated Test vault; the user can pull the public release into production with BRAT.

## Validation

- In installed 7.0.11, a foreground four-page compact-list scroll produced **172** drawing-source metadata lookups from mounted `FileItem` rows. The same call site produced **zero** in installed 7.0.12, with 46 compact rows mounted during the after-check. Other plugin activity differed between runs, so total metadata-call counts and elapsed time are not a controlled before/after comparison.
- Drawing and icon focused tests passed **46/46**; the full repository suite passed **3,250/3,250**. TypeScript, locale usage, TPS namespace, artifact identity, operational identity, and formatting of the changed source file passed. Full ESLint had zero errors and 26 existing warnings. Repository-wide Prettier still reports pre-existing formatting differences in README and other unrelated files.
- The final production build deployed `main.js` and `manifest.json` to the Test runtime; a second build after the README update produced byte-identical artifacts. A guarded reload showed installed 7.0.12 and the Navigator view intact. The Test root's temporary compact appearance was reset to its original standard appearance. Runtime `data.json` differs from its pre-reload SHA only by the expected `lastShownVersion` change from 7.0.11 to 7.0.12.
- Before this patch, a separate warm desktop comparison with all relevant Test-vault consumers enabled measured eight Navigator note clicks at **41.95 ms** median to the correct body and eight core Quick Switcher suggestion clicks at **44.8 ms** median. This is context for ongoing optimization, not evidence of a latency gain from this patch.

Physical-iPhone scrolling, cold startup, and note-creation latency were not measured by this patch. The standard-mode virtual row estimator still reads live drawing metadata when images are enabled to preserve same-mtime drawing-frontmatter updates.
