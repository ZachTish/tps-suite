# TPS Notebook Navigator 5.18.0

TPS Notebook Navigator `5.18.0` makes descendant inclusion a stable per-view choice for folders, tags, and properties.

## Per-view descendant scope

- **Show files from subfolders / descendants** now stores an independent boolean on the active folder, tag, or property
  appearance.
- The existing List setting remains the default for views without an override, preserving every existing vault's
  behavior.
- The toolbar and `Toggle descendants` command update only the active view. Changing one folder no longer changes
  another folder, tag, or property view.
- The vault root remains a fixed complete-vault scope, and Type collections remain outside folder-descendant semantics.
- Resetting a view's appearance removes the stored override and restores inheritance from the List default.

## Compatibility and known limitations

- Backward-compatible minor release with no note-data rewrite or settings migration.
- Descendant overrides are scoped by the existing folder path, tag path, or property-node identity. Renames follow the
  established appearance-metadata rename handling.
- Separate Navigator leaves showing the same logical folder, tag, or property intentionally share that scope's saved
  choice.
- Minimum supported Obsidian version remains `1.11.0`.
