# TPS Notebook Navigator 5.3.1

Released: 2026-08-02

Minimum Obsidian version: 1.11.0

Public API version: 3.2.0

## What changed

- Fixes a desktop horizontal-layout edge case where the list scroll viewport could stop above the bottom of a tall or
  newly expanded Obsidian leaf.
- Gives the horizontal list pane an explicit full-height and zero-minimum-height contract.
- Gives the inner list panel an explicit zero-basis flex contract so the scroller consumes all remaining pane height
  instead of retaining its intrinsic or earlier height.
- Adds a generated-namespace-aware regression test for the complete pane → panel → scroller height chain.

## Compatibility and migration

- This is a backward-compatible layout fix. There are no settings, note, cache, or data migrations.
- Public API 3.2.0 is unchanged.
- The minimum supported Obsidian version remains 1.11.0.

## Validation

- Focused layout and release-metadata coverage passed 12 tests across 3 files.
- Full suite: 226 test files and 2,475 tests passed.
- TypeScript, Prettier, ESLint, stylesheet, TPS source-namespace, operational-identity, artifact-identity, and Git diff
  gates passed. ESLint reported only the repository's 18 existing deprecated compatibility-path warnings and no errors.
- The final production-mode build deployed only `main.js`, `manifest.json`, and `styles.css` to the isolated test
  runtime; all three source and runtime artifacts matched byte-for-byte at version 5.3.1. The runtime-owned `data.json`
  remained in place.
- Obsidian 1.12.7 was reloaded in **Obsidian Plugin Test Vault** and the desktop list viewport was inspected after the
  final build. Production was not changed; this tested public release is intended for the user's BRAT pull.

## Known limitations

- This patch targets the desktop horizontal two-pane layout shown in the report. Vertical and single-pane sizing remain
  governed by their existing dedicated rules.
- The source screenshot was captured in production, but diagnosis, deployment, reload, and verification were confined to
  the isolated test vault.
