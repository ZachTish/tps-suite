# TPS Notebook Navigator 5.8.2

## What changed

- Fixes checkbox rows with task-local hashtags being grouped under `None` or under only the owning note's tags.
- GCM's exact hydrated task tags now populate the row-level `tags` property used by structural sorting and grouping.
- With line-first inheritance, task tags take priority. Combine mode includes both task and note tags. A task with no
  local tags continues to inherit note tags.
- The task context menu and the visible group headers now consume the same exact task-tag source.

## Compatibility and validation

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.11.0.
- Focused provider-row, standalone grouping, Entity Index, and TypeScript checks passed.
- Full automated test, lint, formatting, namespace, operational identity, style, artifact, and final production-build
  gates were run.
- The final artifact was deployed only to the isolated Obsidian Plugin Test Vault runtime; production was not touched.

This public build is ready for a user-controlled BRAT pull.
