# TPS Notebook Navigator 5.14.6

This patch makes automatic daily-note creation honor the configured Daily Notes template across both Core and Notebook
Navigator calendar modes.

## Root cause and changes

- Core-mode creation depended on the in-memory Daily Notes template value, which can briefly be blank while Obsidian
  starts even though a template is durably saved.
- Notebook Navigator's custom-path day mode used only its own optional override; with the default null override it
  intentionally created an empty file and never consulted Core Daily Notes.
- A blank custom-day override now inherits the enabled Core Daily Notes template. An explicit Notebook Navigator daily
  template still wins, and week/month/quarter/year template behavior is unchanged.
- Core date/title variables are rendered against the target date before the custom-path file is created. Bare `{{date}}`
  keeps Obsidian's `YYYY-MM-DD` default independently from the filename format, while `{{title}}` uses the custom
  filename.
- Startup recovery uses the saved folder, filename format, and template as one coherent snapshot. Configured templates
  are resolved and read before any destination folder or note is created, and disabled Core Daily Notes settings are
  never inherited.

## Compatibility and migration

- This is a backward-compatible creation fix; no setting key, note schema, or public API changed.
- Existing explicit Notebook Navigator daily and periodic templates retain their prior behavior.
- Minimum supported Obsidian version: 1.11.0.

## Validation

- Focused tests cover saved-template startup recovery, disabled-Core isolation, explicit override precedence,
  extensionless paths, target-date/title rendering, unaffected periodic templates, and fail-closed folder behavior.
- All 15 focused regressions and the complete 231-file / 2,600-test suite passed. TypeScript, ESLint, style,
  namespace/identity, artifact, and operational gates passed, followed by the mandatory separate production build.
- In reloaded Obsidian 1.13.6, the real **TPS Notebook Navigator: Open daily note** command created `2026/20260810.md`
  from a temporarily configured Core Daily Notes template. The custom filename remained `20260810`, bare `{{date}}`
  rendered as `2026-08-10`, `{{title}}` rendered as `20260810`, and the template body was present.
- The original Daily Notes configuration was restored exactly, the synthetic template and notes were moved directly to
  `_archive`, and the final source artifacts byte-match the isolated test runtime. Production remains untouched.
