# TPS Notebook Navigator 5.14.0

This release makes item creation follow the active Filter Search instead of the underlying navigation selection.

## New

- Constructible searches expose **New matching item** when exactly one supported Type is selected and every requirement
  can be applied deterministically.
- `#hca AND #idea type:structural:task` creates a checkbox with both task-local tags through GCM.
- Exact task `.status=value` and `.key=value` requirements are applied as canonical status and inline fields.
- Type-only searches reuse the Type's existing creation path.

## Safety

- `OR`, negative/untagged, free-text, folder/date/extension/task-state, multiple-Type, key-only or reserved-property,
  unsupported-Type, and Omnisearch queries disable creation.
- The disabled control remains visible and explains why a matching item cannot be guaranteed.
- A nonempty search never falls through to folder, tag, or property note creation.
- No settings or data migration is required.

## Validation

- Focused constructibility-planner, GCM task-payload, and desktop/mobile create-control tests.
- Full Vitest, ESLint, Stylelint, TypeScript production build, TPS namespace/artifact gates, operational-identity gate,
  and atomic test-vault runtime deployment.
- Minimum supported Obsidian version: 1.11.0.
- Visual automation is intentionally skipped while the active Obsidian window is the production vault rather than the
  isolated test vault.
