# TPS Notebook Navigator 8.2.5

Navigator now rejects ordinary Markdown create/modify events before allocating asynchronous icon actions. SVG icon updates still use the existing error handler, icon cache, and single notification timer. Initial note reconciliation no longer produces thousands of discarded promises for an SVG-only feature.

This is a backward-compatible patch with no settings, migrations, new state or provider-cache change. Minimum Obsidian remains **1.11.0**. Existing same-mtime edit invalidation remains intact. This patch introduces no new TPS API/dependency requirement.

## Scope

Existing vault create/modify listeners reject shutdown, non-file and non-SVG events before entering `runAsyncAction`. Eligible SVG callbacks remain synchronous inside that same error handler. The actual icon-list/SVG caches, validation invalidation and existing single 50 ms notification timer are retained. Rename/delete ownership, note indexing, boot metadata events, namespaces, commands and configuration remain unchanged. No listener, cache, poller, state, writer or repair is added.

## Regression validation

Actual registered-handler regressions: each 4,049-Markdown burst goes from 4,049 async actions to zero actions/promises/timers/inventories/reads/writes. Two hundred SVG create/modify pairs preserve 400 synchronous icon actions and one coalesced notification timer.

Nine checks execute the actual registration function, async wrapper and VaultIconProvider cache with a synthetic vault, stubbed icon-service notifications and fake browser timers. The unchanged 8.2.4 baseline fails six target cases and passes three controls. Controls retain SVG cache/list behavior, folder/asset/type/shutdown guards, error reporting and disposal of the one existing notification timer. These are actual source-owner operation counts, not installed frame or physical-input timings.

The final versioned full suite passes **3,330 tests in 285 files** under Node **24.19.0**. Full ESLint reports zero errors and **26 existing warnings**. Namespace, artifact identity, operational identity, scoped source/test formatting and TypeScript/string checks pass. Deployment-suppressed builds preceded the separate ordinary TEST build; the TEST renderer reload verified installed **8.2.5** with all eight active TPS consumers enabled. The separate final post-documentation production build passed with `target=test: unchanged`, retaining the tested artifact bytes below.

## Installed verification and limits

Five **30-second foreground warm-start captures** of the combined GCM 8.1.0, Controller 3.1.8, Health 4.3.2 and Navigator 8.2.5 candidates measured median initial-body milestones **10.868 → 8.514 seconds**, GCM readiness **14.886 → 9.187 seconds**, and Health readiness **15.123 → 9.471 seconds**. Aggregate startup reads increased: raw **36 → 44**, cached **34 → 73–74**; recorded repeated inventories remained **three**. These are combined warm-start results; they do not isolate Navigator's elapsed-time contribution or demonstrate zero startup IO.

One baseline CPU sample and one quiet candidate sample recorded Navigator self CPU **1,494 → 780 ms**, Controller **406 → 26 ms**, and its named debounce callback **367 → 0 ms**. The baseline resumed a test process during capture, so these CPU samples support source attribution but are not controlled timing evidence. Neither warm run showed Navigator bootstrap additions/updates/removals or preview/image regeneration. This patch does not remove a demonstrated cache rebuild; it removes discarded icon-event work on Markdown arrivals.

Health/GCM/Finance/Calendar/Linter data remained byte-identical. Controller persisted only its previously missing existing attachmentSync default; sync-request runtime state may change normally. Navigator's only data change was its existing `lastShownVersion` acknowledgement; restoring that field to baseline **8.2.4** reproduced the original data hash. The actual installed Health/GCM nutrition check restored synthetic in-memory classification/business mappings and instrumentation, retained the original leaf, preserved source formatting and bodies, and archived its two owned fixtures byte-identically. This combined check is not a separate installed replay of Navigator's synthetic 4,049-event handler burst.

Full cold application startup, production, physical-mobile interaction and first-input latency remain unmeasured. Production notes, settings and runtime artifacts were not changed during this implementation or QA. Required index/storage refreshes and other remaining startup/navigation work retain their existing owners.
