# TPS Notebook Navigator 5.14.4

This patch fixes the recurring desktop blank strip by updating the virtualizer's viewport source of truth.

## Fixed

- Rows now continue mounting to the visible bottom when an Obsidian leaf finishes growing after the list virtualizer
  initializes.
- The list viewport observer reports the scroll element's real client width and height, watches the element and its
  workspace ancestors, handles window resizes, and samples the brief startup window for flex-layout changes that
  Chromium does not deliver through `ResizeObserver`.

## Changed

- Removed the ineffective per-row `translateZ(0)` compositor workaround from 5.14.3.
- Kept the established flex pane layout, row renderer, Compact behavior, and item-height measurements unchanged.

## Root cause

The scroller, panel, and pane all occupied the full visible height, but TanStack Virtual could retain the shorter
viewport rectangle measured during bootstrap. It therefore calculated a short visible range and mounted only that range
plus overscan; the empty area began exactly where those mounted rows ended. The 5.14.2 observer called `measure()`,
which resets item-size measurements but does not replace the cached viewport rectangle. The 5.14.3 compositor layers
could not help because the missing rows were outside the mounted virtual range. This release supplies the viewport
rectangle directly.

## Compatibility and migration

- This is a backward-compatible rendering fix with no settings, note, cache, or data migration.
- Public API 3.3.0 is unchanged.
- Minimum supported Obsidian version: 1.11.0.

## Validation

- Focused viewport-observer and generated-CSS regressions passed 27 tests across two files.
- The full suite passed 231 test files and 2,590 tests. TypeScript, ESLint, Stylelint, TPS namespace, operational
  identity, artifact identity, and the production build passed.
- The root mixed-resource list was initialized in a short test-vault window and verified to fill the pane after the
  window grew. The final hot reload displayed 5.14.4 and kept rows rendered through the visible bottom.
- The final build deployed only to the isolated Obsidian Plugin Test Vault runtime. Source and runtime copies of all
  three shipped artifacts match byte-for-byte, and runtime-owned `data.json` remains present. Production was not
  modified.
