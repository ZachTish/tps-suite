# TPS Notebook Navigator 5.8.3

## What changed

- Removes the heavy gray card and stacked button appearance from mobile Checkboxes and other exact-line Type rows.
- Rows return to a clean full-width list with transparent title/source, checkbox, and More actions controls.
- Explicit button resets prevent Obsidian/theme button fills and shadows from leaking into task titles and metadata.
- Two-line wrapping, source metadata, task completion, context menus, touch targets, hover/focus feedback, and
  selected-row feedback remain available.

## Compatibility and validation

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.11.0.
- Focused Type-row layout, formatting, and stylesheet gates passed.
- Full automated test, lint, formatting, namespace, operational identity, style, artifact, and final production-build
  gates were run.
- The final artifact was deployed only to the isolated Obsidian Plugin Test Vault runtime; production was not touched.

This public build is ready for a user-controlled BRAT pull.
