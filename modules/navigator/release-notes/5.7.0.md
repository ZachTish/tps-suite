# TPS Notebook Navigator 5.7.0

## What changed

- Checkboxes and other exact-line Type results now use a compact card-style layout on mobile.
- Long task titles wrap to two lines instead of being forced into one compressed line.
- Source metadata remains visible and truncated safely, while the row and More actions control retain touch-sized
  targets.
- Desktop Type rows and all task completion, opening, and context-menu behavior remain unchanged.

## Compatibility and validation

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.11.0.
- Focused Type-row layout and stylesheet regression checks passed.
- Full automated test, lint, formatting, namespace, operational identity, style, artifact, and final production-build
  gates were run.
- The final versioned artifact was deployed to the isolated Obsidian Plugin Test Vault runtime. Production was not
  touched.

This public build is ready for a user-controlled BRAT pull.
