# TPS Notebook Navigator 5.15.1

This backward-compatible patch fixes tag-scoped Type filtering in the co-installable TPS fork.

## Fixed

- After selecting a tag in navigation, Shift-clicking a built-in Type now keeps the tag as the owning-note scope and
  adds only the Type facet to Filter Search.
- Exact-line Types such as Checkboxes, Bullets, and Headings therefore include rows from tagged notes even when the
  individual row has no matching local tag.
- Explicit `#tag` terms already present in a search continue to filter row-local tags as before.

## Compatibility

- No settings migration is required. TPS Notebook Navigator remains co-installable with upstream Notebook Navigator.
- Minimum supported Obsidian version: 1.11.0.

## Validation

- Focused navigation/search regressions, TypeScript, ESLint, Prettier, Stylelint, locale consistency, TPS namespace,
  operational identity, and generated-artifact checks passed.
- The complete suite passed: 236 test files and 2,697 tests.
- The production-mode build deployed only byte-changed `main.js` and `manifest.json` into the isolated Obsidian Plugin
  Test Vault runtime; Hot Reload then reloaded the changed plugin. Source artifacts byte-match the deployed runtime,
  while runtime-owned state remained outside the deployment scope.
- In the test vault, selecting `dailynote` and applying `type:structural:task` displayed the task from
  `Inbox/Daily/2026-08-02.md` beneath Checkboxes, confirming that the selected note-tag scope reaches untagged task
  rows.
- Production was not accessed or modified.
