# TPS Notebook Navigator 5.6.0

## What changed

- Property grouping now defaults to showing an item once in every group represented by its multi-valued property.
- The Sort and Group menu adds **Multi-value grouping** with **Show an instance in each group** and **Combine values
  into one group**.
- The behavior applies consistently to note rows and structural rows such as tasks, bullets, and headings.
- Repeated property values are deduplicated inside a group, while each rendered cross-group instance keeps a unique UI
  key and the same source identity.

## Compatibility and migration

- Existing saved views use the new one-instance-per-value default when no choice was previously stored.
- Select **Combine values into one group** to restore the earlier comma-separated grouping behavior for a view.
- No note data or frontmatter is migrated. Minimum supported Obsidian version remains 1.11.0.

## Validation

- Focused note-grouping, structural-row grouping, and settings sanitation regression tests.
- Full automated test, lint, formatting, namespace, operational identity, style, and production-build gates.
- Deployed to and validated against the isolated Obsidian Plugin Test Vault runtime.

This public build is ready for a user-controlled BRAT pull after test-vault acceptance.
