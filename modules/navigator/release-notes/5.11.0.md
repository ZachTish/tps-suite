# TPS Notebook Navigator 5.11.0

This release makes GCM-backed task rows draggable as Markdown text and closes the styling gap that allowed attached task
controls to regain gray button surfaces.

## Changes

- Drag a hydrated task row on desktop and drop its complete Markdown task line into an editor.
- Task text drags are isolated from Navigator's file, folder, tag, and property mutation paths, so the containing note
  is never moved or retagged by mistake.
- Checkbox, title, and More controls now use the same flat transparent chrome in attached and standalone Type views,
  including theme-resistant CSS guards.
- Mobile task rows remain one line and retain their existing checkbox, selection, source-opening, and context-menu
  behavior.

## Validation

- Focused provider-row, GCM task-provider, and provider-normalization tests.
- Full Vitest suite, ESLint, Stylelint, TypeScript production build, TPS namespace/artifact gates, and test-vault
  runtime deployment.
- Minimum supported Obsidian version: 1.11.0.

Tested in the Obsidian Plugin Test Vault and ready for the user's BRAT pull. The release does not directly install or
reload the production vault.
