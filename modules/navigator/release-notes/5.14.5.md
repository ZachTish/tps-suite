# TPS Notebook Navigator 5.14.5

This patch closes the remaining desktop lifecycle gap behind the recurring blank section at the bottom of the list pane.

## Fixed

- Rows now remain mounted through the visible bottom after a Navigator leaf is activated, restored from a background
  tab, resized, or expanded after initialization.
- Obsidian's authoritative `ItemView.onResize()` lifecycle now forces the exact view's TanStack Virtual viewport
  rectangle to refresh, even when the DOM dimensions compare equal to the last observer sample.

## Root cause

The pane, panel, and scroller already occupied the full visible height. Version 5.14.4 correctly supplied TanStack
Virtual with the scroll element's rectangle, but it still depended on `ResizeObserver` or a short startup sampler to
announce later changes. Obsidian separately and reliably invoked the view's `onResize()` for desktop leaf and workspace
changes; TPS Notebook Navigator returned from that method immediately on desktop. When Chromium missed the observer
delivery after the startup sampler ended, TanStack retained its earlier mounted-row boundary and the rest of the
physically visible scroller appeared blank.

This release forwards Obsidian's lifecycle through a TPS-namespaced, per-view signal. The viewport observer
force-delivers its current rectangle on that signal so a stale internal TanStack rectangle is refreshed even if the
rounded element dimensions have not changed since the last DOM sample.

## Compatibility and migration

- This is a backward-compatible rendering fix with no settings, note, cache, or data migration.
- Public API 3.3.0 is unchanged.
- Minimum supported Obsidian version: 1.11.0.

## Validation

- Focused viewport-lifecycle and TPS identity regressions passed 26 tests across two files.
- The full suite passed 231 test files and 2,591 tests. TypeScript and ESLint passed.
- In the isolated test vault, the live desktop list pane was shrunk, held beyond the old 180-frame startup recovery
  window, and expanded again. Rows rendered through the newly visible bottom without a blank strip.
- The final versioned build deployed only to the isolated Obsidian Plugin Test Vault runtime. Runtime-owned `data.json`
  was preserved. Production was not modified.
