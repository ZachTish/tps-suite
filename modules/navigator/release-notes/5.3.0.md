# TPS Notebook Navigator 5.3.0

Released: 2026-08-02

Minimum Obsidian version: 1.11.0

Public API version: 3.2.0

## What changed

- Adds **Sort** and **Group** controls to Checkboxes, Bullets, Headings, Code blocks, Callouts, Blockquotes, and Tables.
- Sorts source-backed rows by row title, owning-note filename, configured created/modified timestamp, or a configured
  non-manual frontmatter property. Missing values remain last in either direction and ties are stable.
- Groups source-backed rows by compatible dates or configured non-manual owning-note properties. **Custom** remains the
  intentionally ungrouped choice because custom section headings are file-owned.
- Makes any nonempty internal Filter Search started from a built-in Type search the complete built-in Type catalog.
  Native file matches remain ordinary rows; source-backed matches appear in labeled Type sections and retain their Type
  identity.
- Adds canonical `type:<fixed-id>` and `-type:<fixed-id>` facets. Multiple positive Type facets form a union, while the
  Type dimension intersects with names, tags, properties, dates, folders, extensions, and task-state filters.
- Adds additive Shift-click composition across tags, properties, and built-in Types. A normal navigation selection
  remains the starting scope; modifier clicks add or remove explicit search facets without replacing that scope.

## Compatibility and migration

- This is a backward-compatible feature release. Public API 3.2.0 adds bounded presentation updates for fixed
  source-backed Types and returns each mixed structural result's fixed Type id.
- Existing Type presentation settings need no migration. Unsupported or inherited manual-rank sorting resolves to a
  configured non-manual property when available, then to title order, without rewriting settings.
- The minimum supported Obsidian version remains 1.11.0.

## Known limitations

- Source-backed rows support row title and owning-note sort fields; grouping is limited to compatible dates and
  configured non-manual owning-note properties. File display modes, manual ordering, folder grouping, drag, rename,
  pinning, and file multi-select remain intentionally unavailable for these rows.
- Tag, property, date, folder, extension, and task-state facets constrain the owning note. General inline row properties
  are not published by the current Entity Index contract, so these facets do not independently inspect each block's
  text.
- Plain-text structural search matches the row label and source path, not the full block body.
- Mixed file and structural aggregation is an internal **Filter Search** feature. Omnisearch remains ranked and
  file-only.
- External provider Types retain provider-owned ordering, search, presentation, and the existing 1,000-row safety
  ceiling.
- Mobile interaction is covered by shared modifier logic, component markup, and responsive-CSS regression tests; the
  final release validation was not automated on a physical iOS device.

## Validation

- Focused search, modifier-composition, source-row presentation, settings, refresh, sticky-header, and public-list
  coverage passed 385 tests across 21 files. This includes the exact Tag → Shift-Checkbox → Shift-Tag composition path,
  all seven source-backed search sections, owning-note tag/date invalidation, and grouped provider-row scrolling.
- Full suite: 226 test files and 2,474 tests passed.
- TypeScript, Prettier, ESLint, stylesheet, TPS source-namespace, operational-identity, artifact-identity, and Git diff
  gates passed. ESLint reported only the repository's 18 existing deprecated compatibility-path warnings and no errors.
- The final production-mode build deployed the byte-changed `main.js` and `manifest.json` to the isolated test runtime;
  `styles.css` was already byte-identical. All three source and runtime artifacts matched at version 5.3.0.
- Obsidian 1.12.7 was reloaded in **Obsidian Plugin Test Vault** and displayed the 5.3.0 release dialog. Live desktop QA
  confirmed grouped Checkboxes, the bounded source-Type Sort/Group menu, a mixed search containing native Notes plus
  labeled Checkboxes and Bullets, and direct `type:structural:code-block` filtering with the correct source line.
- The test runtime `data.json` inode was preserved across deployment. UI QA changed no presentation setting. Production
  was not inspected or changed; this tested public release is intended for the user's BRAT pull.
