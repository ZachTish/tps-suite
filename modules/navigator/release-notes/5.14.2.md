# TPS Notebook Navigator 5.14.2

This patch fixes the virtualized list still stopping at an earlier viewport height after 5.14.1 expanded the outer pane.

## Fixed

- The desktop list panel and physical scroller now each occupy a definite remaining-height grid track.
- Real scroller width or height changes schedule one virtualizer remeasurement on the next animation frame, after the
  virtualizer's own rectangle observer has received the final layout.
- Rounded dimensions prevent subpixel churn from creating resize/measurement loops.
- Mobile, vertical, and single-pane sizing remain unchanged.

## Compatibility and migration

- This is a backward-compatible rendering fix with no settings, note, cache, or data migration.
- Public API 3.3.0 is unchanged.
- Minimum supported Obsidian version: 1.11.0.

## Validation

- Focused layout, virtualizer-resize, release-note, and artifact-identity coverage passed 30 tests across 4 files and
  validates both the physical height chain and the virtual row-window remeasurement.
- The full suite passed 231 test files and 2,589 tests. TypeScript, ESLint, Stylelint, TPS source namespace, operational
  identity, artifact identity, and production build gates passed; ESLint reported 19 existing warnings and no errors.
- Every changed file passes Prettier. The repository-wide check retains the three previously committed unrelated
  warnings documented in 5.14.1 rather than folding those files into this patch.
- The final build deployed to the isolated Obsidian Plugin Test Vault. All three runtime artifacts match the tested
  source artifacts byte-for-byte, and runtime-owned `data.json` was preserved. Production was not modified.

## Known limitations

- UI automation is skipped while the active Obsidian window is the production vault; source, generated CSS,
  test-runtime, and published artifacts are verified independently.
