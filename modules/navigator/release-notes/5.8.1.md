# TPS Notebook Navigator 5.8.1

## What changed

- Fixes source-of-truth synchronization when a Type is selected before another filter is added.
- Adding `#hca` while Checkboxes is selected now produces `type:structural:task #hca` in the visible search bar.
- The same symmetric behavior applies to property and date additions, while the earlier property/tag-to-Type behavior
  remains intact.
- Existing facets remain idempotent and are not duplicated.

## Compatibility and validation

- No settings, note data, or frontmatter migration is required.
- Minimum supported Obsidian version remains 1.11.0.
- Focused tests cover the exact Checkboxes-to-tag sequence, property-to-Type, Untagged, idempotency, and focus
  preservation.
- Full automated test, lint, formatting, namespace, operational identity, style, artifact, and final production-build
  gates were run.
- The final artifact was deployed only to the isolated Obsidian Plugin Test Vault runtime; production was not touched.

This public build is ready for a user-controlled BRAT pull.
