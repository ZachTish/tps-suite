# TPS Notebook Navigator 5.18.1

TPS Notebook Navigator `5.18.1` fixes descendant visibility at the vault root.

## Fixed

- The vault root now stores and honors its own **Show files from subfolders / descendants** choice.
- Turning descendants off at the root shows only files stored directly in the vault root; nested folder items are
  excluded.
- **Search whole vault** still temporarily searches every visible folder without changing the root's saved choice.
- Root-level Type and provider results remain constrained to the same effective file scope.

## Compatibility

- Backward-compatible patch with no note-data rewrite or settings migration.
- Existing vaults inherit the global List default until the root control is first changed.
- Minimum supported Obsidian version remains `1.11.0`.

## Validation

- Complete declared suite: `250` test files and `2,782` tests passed.
- Focused descendant, root-scope, appearance, settings-loader, release-note, and artifact regressions: `86/86` passed.
- ESLint, Prettier, Stylelint, TypeScript, string-usage, source-namespace, artifact-identity, and operational-identity
  gates passed.
- The separate production build deployed `main.js` and `manifest.json` to the test-vault runtime; source and runtime
  `main.js`, `manifest.json`, and `styles.css` matched byte-for-byte after reload.
- Test-vault UI QA confirmed that disabling descendants at the selected vault root removed nested-folder items while
  retaining direct-root files, and re-enabling it restored nested results. The temporary root override was removed; no
  QA notes were created.
- Production deployment or installation: **NOT PERFORMED**.
